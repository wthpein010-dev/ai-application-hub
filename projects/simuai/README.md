# 万象实验室

万象实验室把适合量化的自然语言问题转换成可拖动参数、观察曲线并查看假设边界的互动实验。GitHub Pages 公开版只在浏览器中匹配 30 个受控实验：高匹配时直接打开实验，低匹配时展示三个候选，不会把输入发送给远程 AI。

## 本地启动

需要 Node.js 20 或更高版本。在仓库根目录运行：

```powershell
npm run start:simuai
```

然后打开 `http://127.0.0.1:4177`。不配置任何 API 环境变量也能完整使用 30 个内置实验，问题未命中时会展示相近的离线推荐。

本项目使用 ES 模块，必须通过 HTTP(S) 访问。不要双击 `index.html` 以 `file://` 打开；Chrome 会按安全策略拦截模块加载，页面按钮也就无法初始化。

运行验证：

```powershell
npm run test:simuai
npm run test:simuai-browser
```

浏览器冒烟测试优先使用 `CHROME_PATH`，其次使用本机 Chrome 或 Edge。

## 可选的本地 AI 编译代理

API 密钥只由 Node 代理从进程环境变量读取，不会发送到浏览器、写入缓存或进入前端源码。

```powershell
$env:SIMUAI_API_KEY = "your-server-side-key"
$env:SIMUAI_API_URL = "https://api.openai.com/v1/responses"
$env:SIMUAI_MODEL = "gpt-5-mini"
$env:PORT = "4177"
npm run start:simuai
```

`SIMUAI_API_URL`、`SIMUAI_MODEL` 和 `PORT` 均可省略。仅在本机通过 `http://127.0.0.1:4177/?compiler=proxy` 显式打开代理模式时，未命中的问题才会最多触发一次编译请求。公开域名即使附加该参数也始终保持静态模式。

代理默认对同一客户端限制为每分钟 12 次编译请求；这是一层本地进程保护，正式公网部署仍应在网关配置认证、分布式限流和费用告警。

## 模型与实验库

所有实验只能使用九类内置计算引擎：`linear`、`compound`、`decay`、`funnel`、`inventory`、`payback`、`logistic`、`queue`、`probability`。30 个离线实验均衡覆盖生活日常、自然科学、游戏世界、商业决策、社交传播和趣味脑洞六类主题。每个实验声明推荐默认图表，用户也可以在折线、面积、柱状、阶梯和漏斗视图之间手动切换；切换视图不会改变模型指标。

## 安全边界

- AI 上游使用严格 JSON Schema 输出，服务端和客户端还会再次校验模型字段、绝对参数范围与高风险主题；不能生成或执行 JavaScript、HTML、任意表达式或外部资源。
- 参数滑动后的重算完全在本地完成，不会继续调用 AI。
- 每个实验都会显示公式、单位、假设、适用边界和风险提示。
- 不提供账号、云端保存、支付、任意代码生成或现实数据自动查证。
- 所有结果都是基于公开假设的互动估算，不构成医疗、投资、法律或其他专业建议。

## 3 分钟演示路线

1. 用“小游戏每天买量 5000 元，多久能回本？”打开回本实验，调节每日成本和留存率，观察回本日与累计收益曲线实时变化。
2. 展开“为什么这样算”，查看留存队列公式、当前假设和适用边界。
3. 依次打开“咖啡因还剩多少？”与“定期存钱与复利”，演示衰减和复利模型。
4. 输入一个实验库没有的问题，确认当前实验不被偷偷替换，并从三个离线推荐中选择一个。
5. 切换到手机宽度，确认图表可在自身容器内横向浏览，页面本身不产生横向溢出。
