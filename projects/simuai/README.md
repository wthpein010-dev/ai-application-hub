# SimuAI 万物实验室

SimuAI 把适合量化的自然语言问题转换成可拖动参数、观察曲线并查看假设边界的互动实验。应用自带 12 个离线实验；未命中本地实验时，也可以通过可选的服务端 AI 代理生成受控实验说明书。

## 本地启动

需要 Node.js 20 或更高版本。在仓库根目录运行：

```powershell
npm run start:simuai
```

然后打开 `http://127.0.0.1:4177`。不配置任何 API 环境变量也能完整使用 12 个内置实验，问题未命中时会展示相近的离线推荐。

运行验证：

```powershell
npm run test:simuai
npm run test:simuai-browser
```

浏览器冒烟测试优先使用 `CHROME_PATH`，其次使用本机 Chrome 或 Edge。

## 可选 AI 编译

API 密钥只由 Node 代理从进程环境变量读取，不会发送到浏览器、写入缓存或进入前端源码。

```powershell
$env:SIMUAI_API_KEY = "your-server-side-key"
$env:SIMUAI_API_URL = "https://api.openai.com/v1/responses"
$env:SIMUAI_MODEL = "gpt-5-mini"
$env:PORT = "4177"
npm run start:simuai
```

`SIMUAI_API_URL`、`SIMUAI_MODEL` 和 `PORT` 均可省略。未命中的问题最多触发一次编译请求；超时、断网、非法返回或未配置密钥时，应用立即回退到离线实验库。

## 模型与实验库

所有实验只能使用六类内置计算引擎：`linear`、`compound`、`decay`、`funnel`、`inventory`、`payback`。12 个离线实验覆盖生活科普、游戏产品和商业决策，包括咖啡因衰减、小游戏买量回本、定期存钱与复利、睡眠债、体重趋势、学习进度、销售漏斗、订阅增长、库存周期、预算燃尽、活动到场和游戏数值成长。

## 安全边界

- AI 只能返回通过 Schema 校验的 JSON，不能生成或执行 JavaScript、HTML、任意表达式或外部资源。
- 参数滑动后的重算完全在本地完成，不会继续调用 AI。
- 每个实验都会显示公式、单位、假设、适用边界和风险提示。
- 不提供账号、云端保存、支付、任意代码生成或现实数据自动查证。
- 所有结果都是基于公开假设的互动估算，不构成医疗、投资、法律或其他专业建议。

## 3 分钟演示路线

1. 用“小游戏每天买量 5000 元，多久能回本？”打开回本实验，调节每日成本和留存率，观察回本日与累计收益曲线实时变化。
2. 展开“为什么这样算”，查看留存队列公式、当前假设和适用边界。
3. 依次打开“咖啡因还剩多少？”与“定期存钱与复利”，演示衰减和复利模型。
4. 输入一个实验库没有的问题，展示单次 AI 编译以及无 API 时的离线推荐降级。
5. 切换到手机宽度，确认图表可在自身容器内横向浏览，页面本身不产生横向溢出。
