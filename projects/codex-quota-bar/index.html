WHAT STAYS VISIBLE

关键状态，保持在手边。

PROMINENT QUOTA

67%

额度与进度条

主额度用醒目的百分比和横向进度条呈现，扫一眼就知道当前余量。

PET MODE

桌宠融合

检测到可用桌宠时，额度视图可贴靠在身边；点击桌宠即可展开完整信息。

TASK STATUS

任务已完成

完成卡片在任务结束时短暂出现，让进度提醒不再打断当前工作。

DESKTOP FLOW

开机启动与托盘

支持随系统启动，并通过托盘控制显示与隐藏，让桌面保持轻量。

LOCAL FIRST

本机数据与隐私

用量信息仅在本机工具内处理，不读取或上传 auth.json。
