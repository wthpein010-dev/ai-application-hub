# Codex Quota Bar macOS

压缩包同时包含 Apple Silicon（`arm64`）和 Intel（`x64`）两个经过独立验证的应用包。请根据 Mac 的芯片类型打开对应目录中的 `CodexQuotaBar.app`。

首次启动前，可在 Finder 中右键点按应用并选择“打开”。这是一个本地 ad-hoc 签名的修复包；不会读取或上传 Codex 的登录凭据。

## 目录

- `arm64/CodexQuotaBar.app`：Apple Silicon Mac
- `x64/CodexQuotaBar.app`：Intel Mac

应用启动后会在桌面上显示 Codex 用量悬浮条；没有可用桌宠时会使用内置宠物作为本地显示兜底。
