# Codex 待确认悬浮助手｜75 秒演示脚本

公开演示只使用浏览器内的固定示例任务，不读取真实 Codex 数据，不包含账户、聊天、凭据或本机路径。视频无配音，默认启用简体中文字幕。

## 章节

- `00:00–00:10` 安全模拟说明：展示产品名称以及“不读取任务、不发送真实消息”的边界。
- `00:11–00:22` 扫描并显示：点击开始模拟扫描，置顶悬浮栏显示三个待确认任务。
- `00:23–00:35` 拖动位置：拖动绿色标题栏，把悬浮栏移到不遮挡操作的位置。
- `00:36–00:48` 单条确认：点击确认继续，模拟发送固定确认消息并移除该候选。
- `00:49–01:01` 失败与重试：模拟一次发送失败，候选保留并显示重试按钮，重试后移除。
- `01:02–01:15` 一键全部确认：清空剩余候选；悬浮栏回到“暂无待确认 · 常驻扫描”的空闲状态。

## 字幕规则

- 每个章节只有一条字幕。
- 任一时刻只显示一行字幕，章节之间不重叠。
- 使用简体中文和 UTF-8 编码。
