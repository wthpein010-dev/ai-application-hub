# 飞书文件批量下载插件

这是一个嵌入飞书页面内使用的 Chrome / Edge 扩展。安装后打开飞书云文档、网盘或知识库页面，页面右侧会出现「批量下载」浮动按钮，点击即可在飞书页面内打开文件树、筛选器和下载队列。

## 功能

- 在飞书页面内嵌操作面板，不需要打开外部预览页。
- 扫描「我的文件」「共享文件夹」「知识库」中的可导出文档节点。
- 支持文档、表格、多维表格、幻灯片、思维笔记等常见类型。
- 树形展示目录结构，支持展开、折叠、按文件夹级联勾选。
- 支持按文件类型和关键词筛选。
- 下载队列展示单文件进度、成功和失败状态。
- 文件会按来源路径保存到 `Feishu-Export-时间戳` 文件夹下。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：`应用项目/飞书文件批量下载插件`。
5. 打开或刷新飞书页面：`*.feishu.cn` 或 `*.larksuite.com`。

也可以先使用主页中的 `feishu-batch-downloader-extension.zip`，解压后再按上面的步骤加载。

## 使用

1. 确认浏览器已经登录飞书。
2. 在飞书页面右侧点击「批量下载」浮动按钮。
3. 首次打开会自动加载文件树，也可以点面板右上角刷新按钮强制重载。
4. 用类型按钮和搜索框缩小范围。
5. 勾选文件或文件夹后点击「开始下载」。
6. 下载任务会出现在浏览器默认下载目录中。

## 说明

- 浏览器工具栏 popup 保留为备用入口，但主入口是飞书页面内嵌面板。
- 扩展只使用当前浏览器中已登录飞书账号的权限，不绕过登录、分享、企业权限或下载限制。
- 导出任务创建和轮询在飞书页面上下文中执行，以满足飞书 referrer 校验。
- 当前版本直接创建浏览器下载任务，不把所有文件合并成一个 zip。
- 首次全量加载知识库较多时会比较慢，后续会缓存 30 分钟。
