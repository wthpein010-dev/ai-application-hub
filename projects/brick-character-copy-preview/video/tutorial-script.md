# 砖块小人与随身小物图鉴教程脚本

## 录制规格

- 画面：1280×720，H.264，无音轨。
- 时长：约44秒。
- 字幕：WebVTT单行显示，不重叠、不超出视频时长。

## 分镜

1. 展示横版双图鉴工作台：左侧按 Unity 正式顺序同步 45 个角色，右侧预留常驻详情。
2. 打开角色详情，展示完整角色预览图；尚未提供整图的角色沿用正式分层贴图，并检查图鉴描述、获取文案和真实换行诊断。
3. 演示左右换角与收藏，名称、角色形象、文案和诊断结果同步变化。
4. 切换到随身小物，展示默认拥有的 11 件小物和右侧手持试穿预览。
5. 选择告白玫瑰，试穿并保存装扮；确认过程留在右侧，不遮挡左侧清单。
6. 打开独立随身小物交易市场，保留市场价格、获得数量和拖拽整理入口。
