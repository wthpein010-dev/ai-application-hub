# 砖块小人与随身小物图鉴教程脚本

## 录制规格

- 画面：1280×720，H.264，无音轨。
- 时长：约44秒。
- 字幕：WebVTT单行显示，不重叠、不超出视频时长。

## 分镜

1. 展示横版结算图鉴工作台：左侧结算预览、中间 45 个角色图鉴与右侧详情在同一水平线上呈现。
2. 打开角色详情，展示缩小且不越框的完整角色预览图；尚未提供整图的角色沿用正式分层贴图，并检查图鉴描述、获取方式和真实换行诊断。
3. 演示左右换角与收藏，名称、角色形象、文案和诊断结果同步变化。
4. 切换到随身小物，左侧仅展示当前小物本体，中间展示默认拥有的 11 件小物，右侧显示角色装扮效果。
5. 点击小物“告白玫瑰”即可同步装扮右侧角色；再点击“卸下”，确认手持层立即清除，不需要试穿或保存。
6. 打开独立随身小物交易市场，保留市场价格、获得数量和拖拽整理入口。
