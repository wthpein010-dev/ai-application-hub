# 砖块小人图鉴与文案校对教程脚本

## 录制规格

- 画面：1280×720，H.264，无音轨。
- 时长：约42秒。
- 字幕：WebVTT单行显示，不重叠、不超出视频时长。

## 分镜

1. 展示按 Unity 正式顺序同步的 45 个角色，默认全部解锁，3×4 分页与游戏一致。
2. 打开角色详情，展示正式分层贴图、图鉴描述、获取文案和真实换行诊断。
3. 演示左右换角与收藏，名称、角色形象、文案和诊断结果同步变化。
4. 翻到第二页并搜索“毛线架构师”，快速定位任一角色检查实际排版。
5. 打开保留的旧版文案校对表，确认浏览器本地换图能力仍在。
6. 返回图鉴并跳转随身小物交易市场，展示两个工程体验的双向入口。
