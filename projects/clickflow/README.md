# ClickFlow 鼠标自动化工作台

ClickFlow 2.0 是一个 Windows 与 macOS 桌面工具，用于定点自动点击、点击过程录制、动作编辑、JSON 保存和循环回放。

## 选择模式

- **定点点击**：填写 X/Y 坐标、点击间隔、执行次数、按键和按下时长。执行次数为 `0` 时持续运行。
- **录制回放**：录制左键、右键和中键点击，编辑动作顺序与间隔，保存为 JSON 后重复回放。ClickFlow 自身窗口区域内的点击会被过滤，不会进入动作列表。

## 快捷键

快捷键只在 ClickFlow 窗口获得焦点时生效，因此开始和结束录制时不必点击控制按钮。

| 快捷键 | 功能 |
| --- | --- |
| `F6` | 开始或结束录制 |
| `F7` | 开始、暂停或继续回放 |
| `F8` | 开始、暂停或继续定点点击 |
| `F9` | 停止录制、回放和定点点击 |
| `Ctrl+S` | 保存动作序列 |
| `Ctrl+O` | 打开动作序列 |

macOS 如果把功能键用于亮度或媒体控制，可能需要同时按 `Fn`。

## Windows 安装

1. 下载 `ClickFlow-Windows-x64.zip`。
2. 解压整个文件夹。
3. 双击 `ClickFlow.exe`。
4. 首次出现 Windows 安全提示时，先核对下载来源，再确认运行。

## macOS 安装与权限

1. 下载并解压 `ClickFlow-macOS.zip`。
2. Apple Silicon 电脑打开 `arm64/ClickFlow.app`；Intel 电脑打开 `x64/ClickFlow.app`。
3. 未签名应用首次启动时，在 Finder 中按住 Control 点击 `ClickFlow.app`，选择“打开”并核对来源。
4. 在 `系统设置 → 隐私与安全性 → 辅助功能` 中允许 ClickFlow。
5. 如果录制仍不可用，再检查 `系统设置 → 隐私与安全性 → 输入监控`。
6. 修改权限后彻底退出并重新打开 ClickFlow。

不要关闭 macOS 的整体安全机制。

## 如何尽量减少鼠标干扰

默认开启“点击后恢复鼠标位置”。ClickFlow 会在每个动作结束后尽快将光标还原，但真实点击瞬间仍可能影响同时进行的手动操作；点击频率越高，影响越明显。

需要长时间自动化时，建议先固定目标窗口的位置，使用较保守的间隔，并确认 `F9` 可以随时停止全部任务。

## 数据和安全

- 动作序列保存在你主动选择的本地 JSON 文件中。
- 工具不会上传录制的坐标或动作序列。
- 请只在你有权操作的本地应用和合规场景中使用。
