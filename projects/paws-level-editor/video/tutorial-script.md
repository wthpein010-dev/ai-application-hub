# Paws 关卡编辑器教学视频脚本

- 画面：1280 × 720，实际 `projects/paws-level-editor/index.html` 浏览器操作录制
- 时长：约 88 秒
- 声音：无音频，使用默认中文字幕
- 数据：公开静态版 30 个工程关卡，默认打开 `level_0020_r2_第二关模板12.json`；AI 生成和编辑结果只写入当前浏览器

| 时间 | 章节 | 实际操作 |
| --- | --- | --- |
| 00:00–00:12 | 工程关卡库与 AI 生成 | 打开真实静态编辑器，确认 30 个工程关卡和“第二关模板12”默认项；使用“标准 / 均衡布局 / 全部关卡”生成一份可解的浏览器本地关卡。 |
| 00:12–00:32 | 2D 选择、移动和属性修改 | 在生成关卡的真实 2D canvas 上点击一张可见牌，拖动牌面产生坐标变化；随后在右侧可见的 X 属性输入框中再做精确修改。 |
| 00:32–00:50 | 3D 层级与遮挡检查 | 点击“3D”，在真实 WebGL canvas 上拖拽 OrbitControls 相机，再通过 raycast 点击一张可见牌，展示层级和选中反馈。 |
| 00:50–01:10 | 试玩配对 | 切回 2D 并点击“试玩”，在真实 2D canvas 上点击一组可用同类牌产生消除状态；随后切到 3D，在真实 3D canvas 上继续点牌，确认试玩状态跨视图保留。 |
| 01:10–01:28 | 浏览器保存与恢复 | 返回“编辑”和“2D”，保存生成关卡；刷新页面后从列表重新打开它并确认修改保留，最后切回默认的“第二关模板12”。 |

## 录制与转码

运行：

```powershell
node scripts/record-paws-level-editor-demo.mjs
```

脚本使用 Playwright `recordVideo` 记录每一步真实交互，优先使用项目固定依赖 `ffmpeg-static@5.2.0`，也支持通过 `FFMPEG_PATH` 指定二进制。WebM 转为 H.264/yuv420p/faststart MP4，并从 3D 章节抽取 `poster.jpg`。
