# Paws 关卡编辑器教学视频脚本

- 画面：1280 × 720，实际 `projects/paws-level-editor/index.html` 浏览器操作录制
- 时长：约 88 秒
- 声音：无音频，使用默认中文字幕
- 数据：公开静态版内置关卡库为空；录制前导入一个浏览器本地参考关卡，AI 生成和编辑结果只写入当前浏览器

| 时间 | 章节 | 实际操作 |
| --- | --- | --- |
| 00:00–00:12 | 空内置库、本地参考与 AI 生成 | 打开真实静态编辑器，确认“内置关卡库已清空”边界和 Unity 同源动态草地；录制前已导入带两条盲盒轨迹的浏览器本地参考，使用“标准 / 200 张 / 15 个有效层 / 目标 60 分 / 均衡布局 / 全部关卡”在固定 7×8 棋盘生成零同层重叠、图案成对且可解的五阶段塔群，并依次预览表层、掩体、中层、卡点与释放段。 |
| 00:12–00:32 | 7×8 工程网格、2D 安全编辑与截层 | 在边界明确的 7×8 工程网格上选择并安全拖动牌面，修改翻转属性；使用“平铺”从第 20 层开始连续生成 4 张全随机砖块并一次撤销整批，再复制两张牌且保持同层零重叠，最后切到“截层”检查。 |
| 00:32–00:50 | 动态草地与专业 3D 检查 | 点击“3D”，确认 12 组工程草地在 3D 中继续动态呈现，并查看分离的高、中、小塔和盲盒轨迹；核对截层数量与 2D 一致，切换单层后依次演示等距、俯视、正面、侧面，拉开层间距并聚焦一张牌查看遮挡/夹压关系线；再拖拽相机、点选牌面，并验证 3D 删除后可立即撤销恢复。 |
| 00:50–01:10 | 受压阴影、随机、配对、撤回与跨视图试玩 | 切回 2D 并点击“试玩”，确认普通受压砖按 0.58 压暗且真实覆盖区带接触阴影，移除上层后恢复全亮，盲盒背面不重复叠黑；再把一张牌放入槽位后使用撤回，用配对直接消除一对；切到 3D 后确认道具次数保持，并使用随机且不改变牌的身份、坐标和层级。 |
| 01:10–01:28 | JSON 导出、保存、自动恢复与删除 | 返回“编辑”和“2D”，下载可回填 Unity 的 JSON 并保存到浏览器；刷新后由“上次打开”自动恢复该关并确认修改保留，再点击“删除本地”，确认列表和学习参考立即忘掉它并自动回到本地参考关卡。 |

## 录制与转码

运行：

```powershell
node scripts/record-paws-level-editor-demo.mjs
```

脚本使用 Playwright `recordVideo` 记录每一步真实交互，优先使用项目固定依赖 `ffmpeg-static@5.2.0`，也支持通过 `FFMPEG_PATH` 指定二进制。WebM 转为 H.264/yuv420p/faststart MP4，并从 3D 章节抽取 `poster.jpg`。
