能力边界

iOS 沙箱保护你的设备，也限制了桌面能力。

  • ×不能置顶悬浮

    iOS 不允许网页覆盖在其他 App 之上。

  • ×不能读取电脑上的 Codex 任务

    手机网页无法访问电脑本机的任务记录。

  • ×不能启动 Codex CLI

    真实扫描和回复需要 Windows 与 macOS 原生桌面应用。
