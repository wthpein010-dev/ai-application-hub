工作方式

只打断真正需要你的时刻

01

顶部悬停

无候选时只留 10 像素把手；整窗命中区让靠近顶部后的展开保持稳定。

02

查看原任务

每条候选都有查看入口，可先跳到 Codex 对应任务，再决定是否继续。

03

立即续做

可逐条或一键发送；自动确认默认关闭，开启后新候选会直接执行并完成回读核验。

04

保持常驻

普通关闭请求会被拦截；Windows 恢复任务登录时启动，并每分钟检查恢复异常退出的进程。

跨平台边界

桌面负责真实任务，iOS 负责随手体验

Windows 与 macOS原生桌面应用

可连接电脑本机 Codex、常驻扫描、贴顶悬浮，并把确认继续消息发送回对应任务。Windows 包另附登录启动与每分钟恢复安装脚本。

iPhone 与 iPad可安装 Web App

可添加到主屏幕并离线体验流程；受 iOS 沙箱限制，不能置顶悬浮、读取电脑任务或启动 Codex CLI。
