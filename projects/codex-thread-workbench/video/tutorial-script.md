# Codex 待确认悬浮助手 v2.0.0｜86 秒演示脚本

公开演示只使用合成任务标题与匿名内容，不包含真实聊天、账户、文件路径或凭据。视频无配音，默认启用简体中文字幕。

## 章节

- `00:00–00:11` 产品概览：用 86 秒认识 Codex 待确认悬浮助手和四个平台入口。
- `00:12–00:23` 贴顶收纳：无候选时只露 10 像素绿色把手，监控仍在后台运行。
- `00:24–00:35` 自动弹出：扫描发现两个待确认任务后，悬浮栏自动展开但不抢焦点。
- `00:36–00:47` 逐条确认：只向选中的对应任务发送确认继续，另一条候选继续保留。
- `00:48–00:59` 一键全部确认：批量处理当前候选，清空后悬浮栏自动收回屏幕边缘。
- `01:00–01:11` 扫描异常：结果不可靠时进入错误态，停用逐条确认和一键全部确认入口。
- `01:12–01:26` 平台边界：Windows 与 macOS 原生版处理真实本机任务；iOS 是可安装、可离线的伴侣演示。
