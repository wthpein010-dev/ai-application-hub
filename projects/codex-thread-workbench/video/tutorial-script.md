# Codex 多会话工作台｜75 秒演示脚本

公开演示仅使用合成任务标题与匿名内容，不包含真实聊天、账户、文件路径或凭据。视频无配音，默认启用简体中文字幕。

## 章节

- `00:00–00:10` 多任务总览：同一层级展示标题、对话内容与状态。
- `00:11–00:22` 直接对话：在任务卡片内输入“继续检查 Mac 版下载，并补充视频入口。”并发送。
- `00:23–00:35` 状态和管理：查看进行中、已完成、待确认和已停止状态，演示卡片最小化。
- `00:36–00:48` 线程选择：打开线程选择器并搜索“记忆”。
- `00:49–01:01` 原位审批：回到待确认任务，在对应卡片直接允许变更。
- `01:02–01:15` 布局与安全：切换全屏展示，恢复默认布局，停留在不另存聊天和不自动批准的提示。

## 字幕规则

- 每个章节只有一条字幕。
- 任一时刻只显示一行字幕，章节之间不重叠。
- 使用简体中文和 UTF-8 编码。
