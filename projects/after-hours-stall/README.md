# 下班收摊 v1.0.0

拖动小物，一滑到底，遇到纸箱或伙伴才停；滑进右侧同色小摊就收好。全收好即可下班。十关固定布局，可撤销、重开、提示、任选关卡和自动续玩。

代码图形、桃桃/抹茶杯/招财猫、条纹摊位、纸箱、粒子和合成音效均为原创。中文字体为 Google Fonts 官方 Noto Sans SC（SIL OFL 1.1），裁剪及重命名为 Stall Chinese，许可证附在同目录。

版本 1.0.0 / Unity 2022.3.62f3c1。Windows 与浏览器已测，390×844 为模拟触摸，不是手机真机；Mac 未构建/未验证。浏览器清除站点数据会清除存档。

父线程集成资料：integration.json；真实运行截图：screenshots/。仅本目录发布，不修改共享首页、清单或CI。
