## 页面流程

- 金币场：选场、真人匹配、入桌准备、单局牌桌、净额金币结算。开局后保持原座位，可以托管；结束清房，再次入场重新验资。
- 比赛场：查看详情、报名、检录、分桌、自动入桌、小局结果、轮末等待、后续轮次、结果复核及固定奖自动到账。
- 明细：战绩记录、牌局明细与回放参考、赛程、我的赛事、赛季排名、成绩和申诉进度。
- 配套：金币补给、四项独立活动、VIP签到、商品预览、购买确认、订单、交付、装扮装备及宝箱奖励状态。

新手杯每日1次免费在满员锁名单时消耗；此前取消不占次数，后续轮次不重复计算。

周末赛首次锁名单扣1张赛事券，后续轮次与晋级不再扣券，其他券保留。准备超时释放预留，配套页面和草稿保留。

大厅直接点击原图中的场次入口，不叠加重复入口。补给、详情、成绩、规则和结算使用游戏画面内的居中弹板，点击空白、关闭或按Escape回到原页面；确认弹窗关闭不会提交操作。大厅提供游戏画面外的十套设计切换，进入场次后隐藏；游戏内没有人工跳过续局、选择晋级或确认复核按钮。

房外页面沿原路径返回，准备桌左上退出准备；发牌后离桌入口提示继续原局或托管。二级弹板使用右上关闭，配套页面不解除原队列、座位或锁定本金。奖励和订单保留原次状态，重试不重复发奖或扣费。
