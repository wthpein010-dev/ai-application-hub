# 金币场与比赛场 · 交互参考

制作：Pain；2026-10-13；版本1.2.4。

统一蓝金古城风格的网页界面参考。点击游戏画面中的页签、卡片和按钮查看页面跳转。默认界面只保留真实玩家操作，流程由内部模拟服务自动响应。

## 页面流程

- 金币场：选场、确认、真人匹配、入桌准备、单局牌桌、净额金币结算。开局后保持原座位，可以托管；结束清房，再次入场重新验资。
- 比赛场：查看详情、报名、检录、分桌、自动入桌、小局结果、轮末等待、后续轮次、结果复核及固定奖自动到账。
- 明细：战绩记录、牌局明细与回放参考、赛程、我的赛事、赛季排名、成绩和申诉进度。
- 配套：金币补给、四项独立活动、VIP签到、商品预览、购买确认、订单、交付、装扮装备及宝箱奖励状态。

新手杯每日1次免费在满员锁名单时消耗；此前取消不占次数，后续轮次不重复计算。

周末赛首次锁名单扣1张赛事券，后续轮次与晋级不再扣券，其他券保留。准备超时释放预留，配套页面和草稿保留。

大厅直接点击原图中的场次入口，不叠加重复入口。补给、详情、成绩、规则和结算使用游戏画面内的居中弹板，点击空白、关闭或按Escape回到原页面；确认弹窗关闭不会提交操作。没有演示工具栏、人工跳过续局、选择晋级或确认复核按钮。

主页面左上返回大厅，二级弹板使用右上关闭；配套页面不解除原队列、座位或锁定本金。奖励和订单保留原次状态，重试不重复发奖或扣费。

## 演示范围

页面只保存浏览器演示状态，不连接真实账户、匹配、广告、支付、报名或奖励服务，不包含完整麻将引擎。20金币服务费、昵称、在线人数、日期和成绩为演示样例；正式费用、金币转换和渠道配置仍需核定。

签到基础七日合计700金币，有效VIP加成20%后为840；装扮沿现有基础参考价展示。翻牌展示已确定3金币的样例；宝箱120金币礼包仅用于内部测试场景，不能理解为每局必得。固定赛事奖自动到账，没有再次领取操作。

## 打开与检查

`index.html` 直接呈现游戏画面，Hub导航通过合集卡片和独立视频页保留，`demo/index.html` 可直接打开；`video/` 为约65秒、13画面的实际网页截图流程展示，字幕每条一行。

网页运行不需要Node.js。维护时可在`demo/`执行`npm test`运行该项目全部定向测试，执行`npm run check`检查五个脚本。不要求运行Hub全站或其他项目的测试。

本轮弹板按内容重排：状态页960×760，普通功能1200×820，详情和结算1280×860；确认框宽800。弹板内部不再按1920宽缩字，长内容在正文内滚动，主要操作固定在底部。删除实际界面的“返回流程”按钮；原对局重连使用“返回牌桌”。

内部模拟服务：报名后8秒开放检录、检录后5秒发布分桌、牌局30秒产生结果、轮末8秒完成汇总。以上是网页响应时间，不是正式赛事时间。准备60/120秒、全员准备3秒、分桌后3秒、小局间10秒和24小时复核沿原规则。测试通过VM源插桩调用内部回调，正式网页不暴露调试入口。

活动中心、七日茶约、茶歇好礼、回访有礼与好运翻牌统一使用1280×860活动窗口，页签切换及刷新保持尺寸和位置，长内容在正文内滚动。
