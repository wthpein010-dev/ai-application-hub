# 金币场与比赛场 · 交互参考

制作：Pain；2026-10-14；版本1.3.1。

统一蓝金古城风格的网页界面参考。点击游戏画面中的页签、卡片和按钮查看页面跳转。默认界面只保留真实玩家操作，流程由内部模拟服务自动响应。

## 页面流程

- 金币场：选场、确认、真人匹配、入桌准备、单局牌桌、净额金币结算。开局后保持原座位，可以托管；结束清房，再次入场重新验资。
- 比赛场：查看详情、报名、检录、分桌、自动入桌、小局结果、轮末等待、后续轮次、结果复核及固定奖自动到账。
- 明细：战绩记录、牌局明细与回放参考、赛程、我的赛事、赛季排名、成绩和申诉进度。
- 配套：金币补给、四项独立活动、VIP签到、商品预览、购买确认、订单、交付、装扮装备及宝箱奖励状态。

新手杯每日1次免费在满员锁名单时消耗；此前取消不占次数，后续轮次不重复计算。

周末赛首次锁名单扣1张赛事券，后续轮次与晋级不再扣券，其他券保留。准备超时释放预留，配套页面和草稿保留。

大厅直接点击原图中的场次入口，不叠加重复入口。补给、详情、成绩、规则和结算使用游戏画面内的居中弹板，点击空白、关闭或按Escape回到原页面；确认弹窗关闭不会提交操作。没有演示工具栏、人工跳过续局、选择晋级或确认复核按钮。

主页面左上返回大厅，二级弹板使用右上关闭；配套页面不解除原队列、座位或锁定本金。奖励和订单保留原次状态，重试不重复发奖或扣费。

## 演示范围

页面只保存浏览器演示状态，不连接真实账户、匹配、广告、支付、报名或奖励服务，不包含完整麻将或扑克引擎。20金币服务费、昵称、在线人数、日期和成绩为演示样例；正式费用、金币转换和渠道配置仍需核定。

签到基础七日合计700金币，有效VIP加成20%后为840；装扮沿现有基础参考价展示。翻牌展示已确定3金币的样例；宝箱120金币礼包仅用于内部测试场景，不能理解为每局必得。固定赛事奖自动到账，没有再次领取操作。

## 1.3.1 选场与补给

金币场使用左侧玩法分类、顶部模式和三至六档卡片。每卡在点击前显示金币图标和最低准入金额，底分、准入区间、在线人数及服务费分别标明。麻将保留四档；免洗斗地主六档；经典斗地主、够级、掼蛋经典/翻倍与扑克合集五档；过A参考页三档。

本轮先提供竞品参考目录：地方/红中麻将、免洗/经典斗地主、够级六副带龙/普通及开点发四、掼蛋经典/过A/翻倍、跑得快/升级。目录、场档和简要说明由catalogue.js集中维护，各地区暂用同一参考目录；它不是正式地区开放表。扑克模式只演示对应人数与交互，具体牌型和结算引擎尚未接入；不能把30秒样例结果当成对局规则实现。暂未复制竞品未核实的长牌型表、连打、提前个人离桌或付费特权。

金币不足、超过上限、本金锁定分别显示原因。补給保留原玩法和档位，购买或活动到账后返回原选择重新验资，不自动匹配。超额与锁定状态不推荐继续充值。装扮商城与金币礼包是两个入口，装扮消费不能补充金币。

金币礼包展示沿现有投放规划参考值：6/30/68/128/328/648元分别到账3,000/16,500/40,800/83,200/229,600/518,400金币。此网页的支付确认只是浏览器内订单模拟，不发起支付、不产生真实收费；同一模拟订单只到账一次。上述数值并非生产配置发布，不套用微乐的大额金币比例。

匹配、准备和结算人数随玩法变化。斗地主按叫分、加倍、出牌展示；其他扑克显示队伍或对门提示。金币场仍以单局正式结束解锁与清房。比赛仍采用现有四人麻将赛制，竞品借鉴集中在入口、详情、报名状态与奖表展示；未把未核实的竞品晋级参数直接写入正式规则。
