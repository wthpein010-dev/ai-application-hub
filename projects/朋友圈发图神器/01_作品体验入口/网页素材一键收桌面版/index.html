Windows / macOS 桌面工具

把公开网页素材收进一个桌面窗口。

输入网页地址后，工具会扫描图片、视频、音频和常见文档资源。你可以在始终置顶的窗口中筛选、预览并批量下载，适合做设计参考、资料整理与内容采集。

下载源码包 查看 macOS 使用方式

桌面版能力

浏览器端仅提供项目介绍与源码获取；扫描和下载任务在本机桌面应用内执行。

公开资源扫描

识别当前可访问网页内的图片、视频、音频及常见文档资源。

筛选与预览

按资源类型快速聚焦内容，确认后再加入下载队列。

始终置顶窗口

工具窗口可停留在设计稿或浏览器上方，边浏览边收集素材。

使用流程

  1. 01下载源码包并解压到本机目录。
  2. 02安装 Node.js 后，在项目目录执行 npm install。
  3. 03执行 npm start，输入公开网页 URL 后开始扫描与整理。

跨系统使用

源码包同时包含 Windows 与 macOS 的运行、打包配置。Windows 的 .exe 不能直接在 macOS 运行；Mac 需在本机完成依赖安装和应用打包。

Windows

下载源码包后可运行 npm.cmd install 与 npm.cmd start；也可执行 npm.cmd run dist:win-portable 生成便携版。

Intel Mac
