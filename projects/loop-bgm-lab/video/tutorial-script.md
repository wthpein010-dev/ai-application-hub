# 循环乐工房无声教程脚本

## 录制规格

- 画面固定为 1280×720、30fps、H.264 / yuv420p、faststart。
- 成片固定约 72 秒，绝对不含音频流；页面中的播放器也不在录制期间播放。
- 只使用页面自身和仓库内原创合成 `demo-reference.wav`，不使用用户 MP3、受版权保护音乐或个人文件名。
- 字幕每个 cue 只有一行中文，时间不重叠，并与下列画面一致。

## 72 秒分镜

1. **00:00–00:07｜隐私边界**：停留在页首，展示“本地分析”“不上传原始音频”和权利提醒。参考文件只留在本机，不写入导出、日志或 Git。
2. **00:07–00:14｜原创合成参考**：点击“载入原创合成演示 WAV”，等待浏览器内分析完成；允许画面出现这个合成素材文件名。
3. **00:14–00:22｜画像与变量**：展示 D minor、112 BPM StyleSpec，以及基线、旋律音色、律动、打击乐、循环结构五个单变量版本。
4. **00:22–00:30｜人工 Suno 边界**：点击“复制提示词”和“打开 Suno Create”。录制器拦截外部打开，不访问站点、不代替账户登录、不保存凭据，批次状态仍由用户手动更新。
5. **00:30–00:47｜候选比较**：再次使用同一原创合成 WAV 作为安全候选，展示速度、调性、明亮度、动态、循环、时长六项特征，以及风险分类和“不是法律结论”的提示。
6. **00:47–00:55｜授权台账**：把“循环乐工房内置原创合成素材”、仓库内相邻许可声明的公开 GitHub URL、`CC0-1.0` 和 WAV 的真实 SHA-256 写入台账；该 WAV 由 `scripts/build-loop-bgm-demo-wav.mjs` 生成并以 CC0-1.0 献给公共领域。
7. **00:55–01:12｜便携交接**：依次导出 JSON 和 Markdown。两者都不包含音频、绝对路径、个人文件名、Cookie、Token 或恢复密钥，可在另一台电脑继续实验。

## 录制安全门

- 通过本地 HTTP 访问页面；所有页面、控制台、非 2xx、失败请求和未匹配静态请求都会令录制失败。
- `window.open` 在页面初始化前被拦截；只核对请求的是官方 Create URL，不创建弹窗或外部导航。
- 录制器优先尝试 Playwright Chromium，失败后使用本机安装的无界面 Chrome 或 Edge。
- 录制器在页面仍可观察时触发卸载清理，并把每个 `blob:` 中止请求与实际 `URL.revokeObjectURL` 上报逐项核对；随后关闭上下文和浏览器，再统一断言四类错误、普通失败请求、未匹配请求和未归因 blob 中止均为零。
- 八个操作里程碑共用同一个 72 秒故事时钟，每个开始时间必须落在脚本窗口内；录制元数据保存实际时长、完成漂移和故事起点，构建器校验后从该起点裁切。
