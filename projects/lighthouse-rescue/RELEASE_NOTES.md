# 灯塔救援队 1.4.12

2026-10-04 · Unity 2022.3.62f3c1

## 本版变化

- 未来直播消息在主线程处理时若发生意外异常，立即停止消息源和后续队列处理，不发送未完成消息的回执，并尽可能恢复已落盘状态。主播看到独立的“处理故障”诊断。
- 保留俯视航行、三段船上第一人称搜救、风雨雷电、镜头雨滴、水花与光雾粒子、探照灯及同步雨雷音效。玩法视频沿用已验证的 31.67 秒实录，因为本版没有改变可见画面和操作。

## 本地验收

- 故障注入先红后绿；完整 Unity EditMode 128/128 通过。定向 Node 发布与页面测试 3/3 通过。
- Windows x64 ZIP 全新解压后，短路和长路均 `FullSuccess`，救起 3/3，船体分别为 76、82，退出码均为 0。ZIP 44,501,188 字节，SHA-256 `E4E20B79D63012601E5717F2CB40892CBF8F07F4D6527742E0C7A8115E1365CC`。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的。正式接入条件见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
