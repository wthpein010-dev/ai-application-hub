# 灯塔救援队 1.4.8

2026-10-04 · Unity 2022.3.62f3c1

## 本版变化

- 修复未来正式直播模式下的主播“重置”和恢复提示“重新开局”路径：写入新局检查点失败时停止直播源、显示“存储故障”，并尽可能恢复上一局已落盘状态，包括已结算的检查点；不会把未持久化的新局继续用于履约回执。
- 直播断线或等待主播决定恢复上一局时禁止其他主播操作，恢复提示会等直播重连后才能选择。继续保留 1.4.7 的输入过载停机、普通断线排队处理和存储故障保护。
- 航行保留俯视海图；三段搜救保留船头第一人称落难者画面，以及雨浪、阵风粒子、闪电照亮雨丝与水雾、探照灯和同步音效。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。
Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的，页面立刻被强制关闭时，最近操作可能尚未来得及写入浏览器存储。
本版故障注入只验证 SDK 无关的控制器；官方 SDK 的真实重连、队列背压和履约 ACK 仍未验证。
正式接入所需的已核对条件与验收步骤见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
