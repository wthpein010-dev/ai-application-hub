# 灯塔救援队 1.4.6

2026-10-04 · Unity 2022.3.62f3c1

## 本版变化

- 为未来的正式直播消息链路加入存储故障停机：生效事件或主播检查点写入失败时停止消息输入与履约回执，阻断同帧后续事件，尽可能恢复最后可读的检查点与日志，并要求修复存储后重启。
- 主播画面显示明确的存储故障提示；故障后不继续计时、结算或播放风暴音效。普通网络断线仍按原规则处理已入队消息再暂停。
- 航行继续使用俯视海图；三段搜救保留船头第一人称落难者画面，以及逐段增强的雨浪、阵风粒子、闪电、探照灯水雾亮点和同步音效。本版让闪电短暂照亮雨丝、浪花与水雾。

## 本地验收

- Unity EditMode 102/102，包含日志/检查点写入失败、读回失败、回执抑制、同帧队列停机、主播故障提示和雷光粒子反射；WebGL 刷新恢复仍可保留上船 1 人、同一局 ID。
- Windows x64 ZIP 全新解压短路、长路均 `FullSuccess`，救起 3/3，船体分别为 76、82，退出码均为 0。ZIP 43,660,934 字节，SHA-256 `820B282A91FB327C16A8A0E54257CEC916A9A7115268C836A623CB896194A5AB`。
- WebGL 桌面与 390px 手机完整一局通过，没有浏览器错误或横向溢出；截图核对俯视航行与三段第一人称救援。
- 演示视频采用 H.264/AAC，字幕按时段各占一行。公网下载、Pages 和完整 CI 以本次发布的 GitHub 工作流结果为准。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。
Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的，页面立刻被强制关闭时，最近操作可能尚未来得及写入浏览器存储。
本版故障注入只验证 SDK 无关的控制器；官方 SDK 的真实重连和履约 ACK 仍未验证。
正式接入所需的已核对条件与验收步骤见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
