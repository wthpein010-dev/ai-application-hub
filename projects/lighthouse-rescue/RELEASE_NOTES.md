# 灯塔救援队 1.4.14

2026-10-05 · Unity 2022.3.62f3c1

## 本版变化

- 航行、选路和返航保持俯视；三段看见落难者的救援阶段自动切到船上第一人称，暂停救援时保留当段视角。
- 救援视角新增随浪起伏的近景水花粒子和可随照明进度增强的探照灯光束。雨丝、镜头雨滴、光雾与闪电仍按三段险情逐步增强；阵风增加独立音效，受静音和阶段切换控制。
- 修理与照明的进度条统一为 200 设计像素，手机端同样能看清两项协作进度。
- 为未来真实直播接入调整回执时机：规则处理、写盘和 UI 更新之后，等本帧画面完成再把消息结果交给适配器。故障、输入过载或换局时抑制未呈现的回执。当前公开包仍只使用本地模拟事件。
- 玩法视频按本版 WebGL 实机画面重录：正常速度短路一局，加速长路一局；雨、浪、风和雷声音轨由工程素材后期合成，字幕每次只显示一行。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的。正式接入条件见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
