# 灯塔救援队 1.3.0

2026-10-03 · Unity 2022.3.62f3c1

## 本版变化

- 新增最近有效观众贡献提示：上船、投票、修理、照明、点赞与礼物会短时显示昵称和动作；拒绝的指令不进入贡献提示，最多轮播 3 条，换局和恢复后清空。
- 展示昵称与用于去重的用户 ID 分离；匿名显示“观众”，过滤换行、控制符与富文本字符，避免遮住竖屏操作区域。试玩按钮使用“试玩观众”标识。
- 航行、集结、选路、冲刺保留俯视航海图；三段救援分别切换为船上第一人称视角，直接看到三位不同的落难者。
- 救援画面加入聚焦人物的探照灯、固定对象池雨丝与水花、阶段性闪电和冷色短闪；电光折线沿预定方向绘制。风暴随救援阶段加强，暂停时冻结天气运动。
- 新增原创合成的雨浪循环、雷声和救援水花声；闪电后再响雷，静音或结束时立即停止雷声。暂停时保留探照灯与修理、照明进度。
- 介绍视频重新录制为 30.677 秒 Unity WebGL 动态实录，包含新贡献提示、雨浪与雷声音轨、单行中文字幕；Hub 封面使用第二段救援实机画面。
