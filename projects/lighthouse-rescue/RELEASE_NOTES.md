# 灯塔救援队 1.4.11

2026-10-04 · Unity 2022.3.62f3c1

## 本版变化

- 未来直播 SDK 回调进入主线程队列前限制消息 ID、用户 ID、消息类型、评论和房间 ID 的长度；异常超长昵称不留在队列中，但有效互动继续处理。这样队列的 256 条容量也对应有界的文本内存占用。
- 未来正式直播消息现在限制身份键、房间与本局 ID、评论和展示昵称长度。异常超长昵称会回退为“观众”，有效互动仍可写入恢复日志；超长身份键拒绝进入规则，避免触发存储故障停机。
- 每局开始时复制并校验规则参数。完整检查点保存该局参数，恢复和有效事件日志重放继续使用原局参数，避免后来调参改变进行中的救援；旧存档按原默认值兼容，新存档规则缺失或损坏时拒绝恢复。
- 未来正式直播适配器的回执处理发生异常时，控制器立即停止后续消息处理并进入“回执故障”，尽可能回到已落盘状态。此保护尚未经过官方 SDK 和真实直播间联调。
- 继续保留俯视航行、三段船上第一人称搜救、风雨雷电、水雾粒子、探照灯和同步音效。玩法视频沿用 1.4.8 实录，因为本版没有改变可见画面和操作。

## 本地验收

- Unity EditMode 127/127；新增回调队列超大负载和昵称驻留回归测试。Windows 和 WebGL 从 1.4.11 工程重新构建。
- Windows x64 ZIP 全新解压后，短路和长路均 `FullSuccess`，救起 3/3，船体分别为 76、82，退出码均为 0。ZIP 44,501,218 字节，SHA-256 `5A485CB8F2EF70E2B715E0A6F21B8B32A4ED9B36091B757F39E759436F055F89`。
- WebGL 在桌面和 390px 手机浏览器完整一局通过，无页面错误或横向溢出；实际截图核对俯视航行和第一人称救援。刷新恢复后仍保留同局、上船记录及本局规则配置。
- 演示视频沿用 H.264/AAC、单行字幕的 31.67 秒版本。公网下载、Pages 和完整 CI 以本次发布的 GitHub 工作流结果为准。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的。正式接入条件见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
