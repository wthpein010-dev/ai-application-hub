# 灯塔救援队 1.4.5

2026-10-04 · Unity 2022.3.62f3c1

## 本版变化

- 阶段内每条生效操作改为追加可校验的小记录；阶段切换、暂停及结束仍保存完整检查点。恢复时重放日志，保留上船、投票、修理冷却及去重状态。
- 修复刷新恢复后本机指令编号重置造成的重复事件冲突。WebGL 已启用浏览器持久目录同步；页面刷新后可恢复同一局和已记录的上船操作。
- 航行继续使用俯视海图；三段搜救以船头第一人称看落难者，保留逐段增强的雨浪、阵风粒子、闪电、探照灯水雾亮点和同步雷声。暂停、静音和手机画面按现有规则工作。

## 本地验收

- Unity EditMode 96/96；WebGL 刷新恢复实测保留上船 1 人、同一局 ID，暂停后检查点写入浏览器 IndexedDB。
- Windows x64 ZIP 全新解压短路、长路均 `FullSuccess`，救起 3/3，船体分别为 76、82，退出码均为 0。ZIP 44,499,451 字节，SHA-256 `3E2ADC89FD69970F3BB1DDD8C054A8A0A6FBAFB3DD8C45D07AAA53041C551B2F`。
- WebGL 桌面与 390px 手机完整一局通过，没有浏览器错误或横向溢出；截图核对俯视航行与三段第一人称救援。
- 演示视频采用 H.264/AAC，字幕按时段各占一行。公网下载、Pages 和完整 CI 以本次发布的 GitHub 工作流结果为准。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，尚未连接真实抖音直播间。正式直播仍需开发者玩法权限、官方 SDK、真实房间联调和平台审核。
Windows 写入使用同步刷盘；WebGL 持久目录同步到 IndexedDB 是异步的，页面立刻被强制关闭时，最近操作可能尚未来得及写入浏览器存储。
正式接入所需的已核对条件与验收步骤见 [`docs/lighthouse-rescue-live-sdk-readiness.md`](../../docs/lighthouse-rescue-live-sdk-readiness.md)。
