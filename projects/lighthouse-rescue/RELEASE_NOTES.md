# 灯塔救援队 1.1.0

2026-10-03 · Unity 2022.3.62f3c1

## 本版变化

- 夜海、礁石灯塔、救援船和待救者标记换为统一的手绘风格资源；保留原有可编辑 Unity 工程与素材来源记录。
- 加入船只摇摆与尾流、扫动灯束、移动风雨、受损闪烁、救援提示和礼物庆祝光效。礼物仍不影响路线、船体或救援结果。
- 投票时显示船长平票裁定按钮；阶段外隐藏。操作反馈改为玩家可读的中文。
- 主播重置或放弃旧局后写入新局检查点，启动时不再恢复已放弃的进度。
- 同步重录 32 秒 Unity WebGL 阶段演示与预览图，更新 Windows x64 下载包。

## 已验证范围

- Unity EditMode 30 项测试通过；Windows x64 新包在独立解压目录启动并完成短路完整救援 3/3。
- WebGL 在桌面与 390px 触控浏览器完成整局；演示视频在浏览器实际播放。
- 本版 Windows ZIP 大小为 41,020,627 字节，SHA-256 为 `B6918E1B0EE6E652813DBA67381ACF6F22D58CDD69822AA6301A29D45F19C586`。

## 发布边界

Windows 与 WebGL 均为本地模拟模式，未连接真实抖音直播间。正式直播上线需要开发者玩法权限、官方 SDK、真实房间联调与平台审核；取得这些条件前不应将本版称为已接通弹幕的正式直播产品。
