# 灯塔救援队 1.2.0

2026-10-03 · Unity 2022.3.62f3c1

## 本版变化

- 航行、集结、选路、冲刺保留俯视航海图；三段救援分别切换为船上第一人称视角，直接看到三位不同的落难者。
- 救援画面加入聚焦人物的探照灯、固定对象池雨丝与水花、阶段性闪电和冷色短闪。风暴随救援阶段加强，暂停时冻结天气运动。
- 新增原创合成的雨浪循环、雷声和救援水花声；闪电后再响雷，静音或结束时立即停止雷声。暂停时保留探照灯与修理、照明进度。
- 介绍视频改为约 30.59 秒 Unity WebGL 动态实录，带雨浪与雷声音轨、单行中文字幕；Hub 封面使用第二段救援实机画面。
