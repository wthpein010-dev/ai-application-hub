# 叮当打包铺 v1.0.0
原创轻休闲空间装箱谜题。鼠标或单指拖动小物，点击旋转，填满纸盒后贴签寄出。10 个手工关卡，参考解答、撤销、重开、选关及本地进度。
美术：原创程序化扁平卡通，圆角纸盒、贴纸、小物表情、彩纸庆祝；音效：程序合成。
字体：Noto Sans CJK SC，SIL Open Font License，许可见 Assets/Resources/FONT-LICENSE.txt。
Unity：2022.3.62f3c1。构建方法：Unity -batchmode -quit -projectPath <本目录> -executeMethod ParcelBuild.WebGL -buildTarget WebGL。
仅为游戏工程，未包含任何公司品牌或私有素材。
