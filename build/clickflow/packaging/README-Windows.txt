ClickFlow for Windows x64
=========================

运行：
1. 解压整个 ClickFlow-Windows-x64.zip。
2. 双击 ClickFlow.exe。
3. Windows 首次运行若显示安全提示，请确认文件来源后再选择运行。

快捷键（ClickFlow 窗口获得焦点时）：
- F6：开始或结束录制
- F7：开始、暂停或继续回放
- F8：开始、暂停或继续定点点击
- F9：停止全部任务

提示：
- 默认会在自动点击后恢复光标，但点击瞬间仍可能影响手动鼠标操作。
- 录制时，ClickFlow 自身窗口区域内的点击不会加入动作列表。
- 请只在你有权操作的本地应用和合规场景中使用。
