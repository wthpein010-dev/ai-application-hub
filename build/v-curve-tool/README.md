# V 曲线对比工具 1.5.0

完全离线的关卡结构对比工具。左右可独立导入、独立切换 JSON，导出 PNG 和分析 JSON；工具只读关卡，不修改 Unity 工程。

## 开箱使用

完整解压 `V曲线对比工具-1.5.0-开箱即用-Windows-x64.zip`，双击其中的 `V曲线对比工具-1.5.0-Windows-x64.exe`，无需安装 Node.js。

启动即展示“羊 900121 × Paws level_0020”的原图参考示例。左侧还保留用户提供的 `game_map.json` 全部 36 个版本、30 个编号及 900121 备用；右侧自动加载同目录 `Editorlevel` 的 32 个当前工程关卡。下拉框切哪侧，只改变哪侧。导入左侧文件后仍保留内置羊库。

“加载原图示例”恢复参考关卡、参考模型、300 Seeds、1 槽、贪心策略，不清空已有导入库。右侧参考样例为 **17 种图案的历史快照**；当前 `level_0020` 文件为 **19 种**，两者明确分列，不偷偷改写导入参数。

Windows 包未使用商业代码证书签名，可能出现“未知发布者”提示。ZIP 和 EXE 均附 SHA-256 校验。macOS 包包含 Apple Silicon / Intel 两套原生应用，由相应 GitHub runner 分别构建并实际启动验证；采用 ad-hoc 签名，未做 Apple 公证。

## 两种明确的分析口径

| | 参考模型 | 工程模型 |
|---|---|---|
| 用途 | 复现所给截图的算法口径 | 按当前本地工程配置评估 |
| 上层覆盖 | 重叠面积 ≥25% | 任意正面积重叠 |
| 同层侧锁 | 关闭 | 关闭（客户端已于 2026-08-25 关闭） |
| 横轴 | 离场进度，含暂存砖 | 真正消除的进度 |
| 配牌 | 每对独立随机取图案 | 工程随机子组、爽消排序和平铺同深调整 |
| 纵轴 | 左右独立，接近原图 | 左右共享，便于数值比较 |

两种模型均使用“两两配对＋暂存槽”，**不是羊原作的七槽三消玩法，也不是真人通过率预测器**。羊数据在这里用于提供几何结构，采用 1–15 图案池。

参考模型保留原图的种子、逐砖贪心评分、候选搜索及采样规则。1 槽时，奇偶离场进度对应空槽/占槽的不同条件样本，所以曲线产生密集锯齿；不能把锯齿直接解释为玩家压力波动。MC 仅显示至少 5% 种子有样本的进度，不补零或把尾巴拉到 100%。表格采用 P10 / P50 / P90 顺序，参考指标取不小于目标进度的首个有效采样点。

原图“河道下界只统计首轮长度”的截断错误已修复：羊示例下界延伸至 100%，Paws 至 97.83%；保留原有效前缀，不故意复刻错误截断。河道是 T=1、无槽、有限重启的搜索包络，并不是经过穷举证明的绝对边界。E[V] 是覆盖 DAG 的近似，忽略合法移除顺序，不是真实平均或严格上界。

工程模型优先读取 `designerNote.levelData`，支持合法 `metaType/metaData` 随机图案区间；首关保障、动态砖等未完整模拟的机制会标为“不完整”。不能据此宣称完全复刻客户端。

屏幕、PNG、JSON 均保留模型版本、横轴定义、参数和配置指纹；参考报告附有效样本数。FNV-1a32 指纹用于识别配置变化，**不是安全哈希**；导出文件名包含模型名以防混淆。

## 数据来源与开发

羊库来自用户提供的 `game_map.json`，SHA-256：`560aee3b6502919f14ebf17e1d661678e676c14087a4cc242591329b509be60a`。只解析 `map_data`，不执行其余文本。参考快照与逐点回归基准独立保存在 `src/data/reference-sample.json` 和 `tests/fixtures/reference-curves.json`。

右侧 2026-09-08 快照保存在 `bundled-levels/EditorLevels-v150`，32 个 JSON 和 32 个 Unity 元数据文件，打包后目录名为 `Editorlevel`。旧版本快照保留，不作为新版数据源。

单文件网页 `dist/V曲线对比工具.html` 也可直接用 Edge/Chrome 打开。网页因浏览器安全限制不能静默读取本地工程目录，但会直接显示内置原图示例；真实关卡通过对应侧按钮导入即可。

```powershell
npm ci
npm test
npm run verify:real
npm run build
npm run verify:dist
npm run verify:electron
npm run verify:electron:bundled
npm run package:bundled
npm run verify:win
npm run verify:bundle
```

macOS 构建命令为 `npm run build:mac:arm64` / `npm run build:mac:x64`，需在对应平台执行。审计以原参考两关 12 条线、真实 32 关、左右独立导入、导出、Worker 取消和多尺寸布局为回归范围。
