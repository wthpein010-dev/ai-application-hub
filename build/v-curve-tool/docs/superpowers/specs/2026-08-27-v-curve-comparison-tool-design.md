# V 曲线对比工具设计

## 1. 目标

交付一个可离线运行的独立网页工具。用户双击成品 HTML，选择
`E:\Mahjong\PawsHomeClient\Assets\Editor\Res\Config\Gameplay\EditorLevels`
文件夹后，工具自动读取其中的正式关卡 JSON，允许选择任一关卡，并生成该关卡与内置《羊了个羊》900121 结构的 V 曲线对比报告。

报告视觉上复现参考截图的核心效果：深色双图并排、五组曲线、关键指标对比表、口径说明和结构诊断；同时纠正旧归档算法与当前 Unity 运行时不一致的地方。

## 2. 交付形态与边界

- 成品为单个 `dist/V曲线对比工具.html`，Edge/Chrome 双击即可运行，运行时不联网。
- 源码、测试、说明文档和成品都放在本独立工具目录，不修改 `E:\Mahjong\PawsHomeClient`。
- 使用文件夹选择器批量导入；浏览器安全机制不允许网页静默读取绝对路径，因此用户每次打开后需要主动选择一次文件夹。
- 默认忽略 `.meta`、非 JSON 文件、相对路径中包含 `_Trash` 的文件。
- 同时支持拖入或选择单个/多个 JSON，以便快速分析单关。
- 羊 900121 数据内置在成品中；仅借用它的结构，统一按 Paws 两两配对玩法评估，不使用羊了个羊七槽三消规则。
- 不发布到互联网，不修改或回写导入的关卡文件。

## 3. 已核对的真实输入

### 3.1 Paws 正式关卡

2026-08-26 现场读取结果：`EditorLevels` 顶层有 25 个正式 JSON，砖数为 10～370，统一使用新格式：

```text
id,name,difficulty,gridUnit,designerNote,features,bagOffer,tiles,stacks
```

`tiles[]` 字段为：

```text
x,y,layer,type,moldType,metaType,metaData,presetColorType
```

关卡的实际随机池配置位于 `designerNote` 内嵌 JSON：

- `blockTypeCount`：`type=0` 的限定随机池上限；
- `fullRandomTypeMin/fullRandomTypeMax`：`type=-1` 的全随机池范围；
- `pseudoRandomLimitedMode/pseudoRandomFullMode`：伪随机开关；
- `gameLevelOrder`：第一关/第二关出盘逻辑。

当前 `level_0020_r2_第二关模板25.json` 已是 280 砖、22 层、全随机 1～15，不再是旧归档的 368 砖、21 层、17 种。

### 3.2 羊 900121

内置基准来自用户提供的 `归档.zip/900121.json`：258 砖、23 层、15 种图案原始配额。解析时将 `levelData` 的分层对象扁平化为统一砖块数组，并把 `rolNum/rowNum/layerNum` 映射为 `x/y/layer`。

## 4. 统一数据模型

解析器输出：

```js
{
  id: string,
  name: string,
  source: "paws" | "sheep",
  sourceFile: string,
  tiles: Array<{
    id: number,
    x: number,
    y: number,
    layer: number,
    type: number,
    moldType: number,
    metaType: number,
    metaData: number,
    presetColorType: number
  }>,
  rules: {
    gameLevelOrder: number,
    limitedTypeMax: number,
    fullTypeMin: number,
    fullTypeMax: number,
    pseudoRandomLimitedMode: number,
    pseudoRandomFullMode: number
  },
  warnings: string[]
}
```

所有数值字段必须是有限整数；空关、重复的 `(x,y,layer)`、奇数随机组和无法解析的 `designerNote` 产生明确警告或错误，不能静默生成误导曲线。

## 5. 运行时 V 口径

### 5.1 当前 Paws 规则

结构仿真对齐当前 `SheepBoardLayout`、`LevelSceneCoverageIndex` 与 `LevelDataManager.CountAvailableBoardTiles()`：

1. 砖未被移除；
2. 砖不在暂存槽；
3. 任意更高层砖与其 8×8 足迹存在正面积相交，则该砖被覆盖；
4. 同层、同 y，且 x-8 与 x+8 两侧砖同时仍在盘面，则该砖被侧锁；
5. 背面砖仍可点击翻开，因此 `faceDown/presetColorType` 不从 V 中排除；
6. 从暂存槽移出并回盘的砖若处于 `evacuatedFromTray` 状态可操作，但首版无道具仿真不主动使用该能力。

因此运行时 V 为：未移除、不在槽位、未被覆盖且未被侧锁的砖数。

### 5.2 与旧资料的差异

旧 HTML 按“重叠面积 ≥25%”判断覆盖且没有侧锁；当前 Unity 运行时是“任意正面积重叠即覆盖＋侧锁”。新工具一律以当前运行时为实际曲线口径。

## 6. 五组曲线

### 6.1 经验河道上沿/下沿

- 把全部砖视为同一花色（T=1），不使用暂存槽。
- 每步从当前可操作砖中移除一对。
- 上沿策略选择使下一状态 V 尽量高的砖对；下沿策略选择使下一状态 V 尽量低的砖对。
- 默认各运行 20 个确定性重启，以逐点最大/最小合成经验包络。
- 这只是有限搜索得到的“经验河道”，不是穷举证明的数学绝对边界；界面不得使用“任何真实曲线必然落在两线之间”之类绝对措辞。
- 下沿在 `V<2` 时截断并计为无槽结构窄脖子；真实 1 槽玩法有可能拆开单柱，报告必须注明差异。

### 6.2 覆盖 DAG 的 E[V] 理论参考

- 覆盖 DAG 只使用上层覆盖关系，不把侧锁写进祖先锥。
- 对每砖计算传递祖先数 `c(i)`，再按超几何公式计算均匀随机移除集合下的期望：

```text
E[V(m)] = Σ C(N-c(i)-1, m-c(i)) / C(N,m)
```

- 该线明确标为“覆盖 DAG 理论参考（忽略侧锁与合法顺序）”，不得称为真实上界或真实平均。

### 6.3 蒙特卡洛 P10/P50/P90

- 默认 300 seeds、1 个暂存槽、无道具、贪心策略。
- 固定 `type>0` 保留；`type=0` 按限定池成对分配；`type=-1` 按全随机范围成对分配。
- 羊 900121 按 15 种图案的成对池分配，仅借结构。
- 贪心策略每步优先选择让动作后 V 最大的现成对子；无对子时，在槽未满的条件下暂存让动作后 V 最大的一砖。
- 若槽已满且没有可消对子则卡死。
- 横轴使用真实清除进度 `removed/N`；暂存动作不增加清除进度，同一进度保留动作后的最新稳定 V。
- 仅在仍有至少 5% seeds 提供样本的进度点绘制分位数，避免后段幸存者极少时制造伪稳定曲线。

## 7. 指标与诊断

每侧报告：

- 砖数、层数、实际随机池；
- 开局 V；
- MC P10/P50/P90 @25% 与 @50%；
- 中盘经验河道范围；
- 无槽下沿结构窄脖子次数/平均终止进度；
- 无道具清盘率；
- 卡死局平均终止进度。

对比表按羊 900121 与当前 Paws 关卡分列。诊断器根据曲线数据识别：开局过窄、前 20% 快速跳水、中盘低位横盘、40%～60% 断崖和后段窄脖子。诊断文案必须引用具体数值和进度，不生成无依据的自然语言结论。

## 8. 界面与交互

### 8.1 首屏

- 深色高对比背景，标题为“V 曲线对比 · 羊了个羊 900121 vs Paws”。
- 顶部导入区突出“选择 EditorLevels 文件夹”，并显示目标路径提示。
- 导入后显示成功文件数、忽略数、警告数；左侧或顶部关卡选择器列出全部正式关卡。
- 默认选择导入后的 `level_0020`；不存在时选择砖数最多的正式关卡。

### 8.2 报告

- 两张图并排，左为羊 900121，右为所选 Paws 关卡；小屏改为上下排列。
- 两图横轴统一为 0%～100%，纵轴使用相同最大值，保证视觉可比。
- 图例依次为经验河道上沿、经验河道下沿、E[V] 理论参考、MC P90、MC P50、MC P10。
- 鼠标悬停显示进度与各线数值。
- 曲线下方显示对比表、口径脚注和诊断卡片。
- 控件允许修改 seeds（20～2000）、槽位（1～2）和策略（贪心/随机），修改后重新计算。
- 计算在 Web Worker 内执行；显示阶段进度，可取消，切换关卡时旧任务结果不得覆盖新任务。

### 8.3 导出

- “导出 PNG”将当前完整报告区域保存为 2× 清晰度 PNG。
- “导出分析 JSON”保存导入关卡摘要、参数、曲线点、指标、诊断和口径版本。

## 9. 错误处理

- 未选到有效 JSON：保留导入页并说明未发现正式关卡。
- 单文件 JSON 损坏：跳过该文件，列出文件名与错误，不影响其他文件。
- 空 `tiles`：该关不可分析，不能进入报告。
- 不支持的动态砖或非零 `metaType`：结构曲线仍可计算，但 MC 标记为“玩法仿真不完整”。
- 奇数随机组：保留结构分析，MC 明确标记无效出盘，不用自动补牌掩盖问题。
- Worker 异常或取消：保留上一份有效报告并显示状态，不清空用户已导入列表。

## 10. 技术结构

- Vanilla JavaScript + Vite；不引入 UI 框架。
- `vite-plugin-singlefile` 将 JS、CSS、Worker 和 900121 数据内联为一个成品 HTML。
- 核心算法为纯函数模块，可在 Node/Vitest 中直接测试。
- Canvas 自绘曲线；`html2canvas` 只用于完整报告 PNG 导出。
- Web Worker 执行结构建图、理论线、经验河道和 MC，主线程只负责导入、状态与渲染。

- Paws 新格式、`designerNote` 和羊分层格式解析。

- 上层任意相交覆盖、无相交不覆盖、同层左右侧锁、移除一侧解锁、背面砖计入 V。
- 类型池按 `type=0/-1/>0` 正确分配，固定 seed 可复算。
- E[V]、河道、MC 在小型手算棋盘上返回预期点。
- 300 seeds 同参数重复运行结果逐点一致。
- 诊断和导出 JSON 不含 `NaN/Infinity`。

- 羊 900121 解析为 258 砖、23 层、15 种。
- 当前 `level_0020` 解析为 280 砖、22 层、全随机 1～15。
- 选择整个 `EditorLevels` 后可看到 25 个正式关卡。
- 300 seeds 分析能完成，曲线、表格和诊断全部来自计算结果。

### 11.3 视觉与运行验收

- 在 2048×1180、1440×900 和 750×1624 检查布局。

- `dist/V曲线对比工具.html` 在无开发服务器、无网络条件下双击可用。
