# 月面货运任务线第一版

目标：保留已验收的月面车辆物理，为现有公网游戏增加四名 NPC、三段连续任务、五次交付、货物重量与完整度评价；美术用 Blender 生成可复用模型和贴图。

用户已要求直接集中完成，采用简短方案后实施，不进行逐项设计确认。参考文章因浏览器安全策略阻止访问未读取，已请用户提供正文；不猜测文章技术。

- [x] 任务逻辑：调度员授权 → 三基地设备交付 → (100,68) 找回 D 箱送 B → B 的易损电源 E 箱送 C；站点 NPC 对话、声望和最终评级。
- [x] 货物：重量影响车体质量；高速碰撞降低完整度并掉落，保留拾取与复位，低完整度不会锁死任务。
- [x] 场景：复用物理代理，加载 Blender GLB 的 NPC、车体、车轮、基地、货箱与嵌入纹理；缺少模型时保留可运行的基础图形。
- [x] 界面：任务目标、对话、货物清单/完整度/重量、地图 NPC 标记、五次交付的结算；保留三镜头与触屏操作。
- [x] 验收：先写任务线失败测试；通过既有物理、任务线与真实输入路线测试、类型检查及构建；浏览器从接单到五次交付通关，验证对话、模型与重开。
- 发布目标与线上门禁：沿用原 Hub 小游戏入口和仅本项目无视频例外，更新截图/介绍，GitHub Pages 公网验收。

分工：根代理维护 simulation/campaign/runtime/scene、验收和发布；素材代理只维护 assets-source/public/assets；界面代理只维护 page.tsx/globals.css。
