# Paws 实机视觉还原实施计划

> 依据：`docs/superpowers/specs/2026-07-21-paws-gameplay-visual-fidelity-design.md`

## 任务 1：锁定资源和页面契约

1. 在 `tests/paws-level-editor-assets.test.mjs` 增加 gameplay 资源文件、PNG 尺寸、相对引用和隐私断言。
2. 增加舞台 HUD、功能按钮、2D 合成和 3D 实机材质的源码契约测试。
3. 运行定向测试并确认因资源/实现缺失而失败。

## 任务 2：同步 Unity 美术资源

1. 创建 `projects/paws-level-editor/assets/gameplay/`。
2. 机械复制底板、锁定蒙层、草地、设置、洗牌、重玩和双暂存槽 PNG。
3. 校验文件尺寸和字节可读性，不修改 Unity 工程源文件。

## 任务 3：实现舞台布局

1. 在 `index.html` 增加关卡 HUD，并把现有适配、重玩、洗牌控件换成实际资源皮肤。
2. 在控制器中绑定 HUD 适配按钮、当前关卡标题和实机资源 URL。
3. 在 `styles.css` 中实现草地舞台、稀疏草纹、试玩底部动作区和响应式缩放。

## 任务 4：实现 2D 实机砖块和暂存槽

1. 为底板、锁定蒙层和图案建立独立图片缓存。
2. 按 120:135 合成砖块，保留编辑态层级和选择反馈。
3. 使用 `play_save2.png` 绘制双槽并对齐命中区域，保证暂存仍可交互。

## 任务 5：实现 3D 实机舞台

1. 使用真实底板和图案合成顶面纹理，侧面切换为实机深绿色。
2. 场景背景和地面切换为草地；编辑态保留网格，试玩态隐藏。
3. 增加双槽地面平面并对齐两个暂存牌位置，完善资源释放。

## 任务 6：回归、录屏与发布

1. 运行全部 Paws Node 测试、模块语法检查、`git diff --check`。
2. 运行桌面和 AI 浏览器 smoke，截取 1440×900 与移动端证明图并人工检查。
3. 真实重录教程，运行视频解码、章节、哈希和画面门禁。
4. 提交变更，整合最新 `origin/main`，推送 `main`。
5. 等待 GitHub Pages 部署，完成线上 HTTP、Range、桌面和移动端浏览器验收。
6. 更新 AI Application Hub 和麻将项目长期记忆。
