# SimuAI 万物实验室 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个可离线演示、可选联网编译自然语言问题、并通过受控模型生成互动实验的 SimuAI Web 应用。

**Architecture:** 原生 ES 模块将模板、Schema 校验、六类模型引擎、结论呈现、SVG 图表和 UI 状态解耦。浏览器先走本地模板匹配，未命中时调用同源 Node 代理；代理只接收严格 JSON，前端再次校验后才渲染，任何参数变化都只触发本地计算。

**Tech Stack:** HTML5、CSS、原生 JavaScript ES modules、SVG、Node.js 20+ 内置 `node:test`、Playwright 1.61.1、Node 内置 HTTP/fetch。

## Global Constraints

- 首版必须在 1–3 天范围内保持单页、单用户、无账号、无云端保存。
- 只支持 `linear`、`compound`、`decay`、`funnel`、`inventory`、`payback` 六类受控模型。
- AI 只能返回严格 JSON；不得执行 AI 生成的 JavaScript、HTML、表达式或外部资源。
- API 密钥只能从代理进程环境变量读取，不得进入前端、仓库、日志或浏览器缓存。
- 内置 12 个实验必须在无 API 环境中完整可用。
- 参数变化只在本地计算，不得产生额外网络请求。
- 所有实验必须展示公式说明、单位、假设、适用边界和“互动估算，不构成专业建议”提示。
- 桌面 `1440×900` 与移动端 `390×844` 不得产生横向溢出。
- 医疗、投资、法律和安全主题不得输出确定性预测。

- [ ] **Step 3: 实现最小 Schema 与六类纯函数引擎**

```js
export const MODEL_TYPES = Object.freeze([
  "linear", "compound", "decay", "funnel", "inventory", "payback",
]);

export function runModel(spec, inputValues) {
  const values = Object.fromEntries(
    Object.entries(inputValues).map(([key, value]) => [key, Number(value)]),
  );
  if (Object.values(values).some(value => !Number.isFinite(value))) {
    throw new RangeError("All model inputs must be finite numbers");
  }
  return engines[spec.modelType](spec, values);
}
```

为每类引擎返回统一结构：

```js
{
  series: [{ x: 0, value: 0 }],
  outputs: { finalValue: 0 },
  warnings: [],
}
```

代理限制请求体 8 KiB、问题 300 字、上游 8 秒超时；提示词列出允许模型、允许字段和 12 个参考模板，要求仅返回 JSON。上游缺失或失败时返回不含内部细节的错误码。
