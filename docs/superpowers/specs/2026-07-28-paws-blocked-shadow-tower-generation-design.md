# Paws 关卡编辑器：遮挡压暗与塔群生成设计

日期：2026-07-28

## 目标

1. 2D 与 3D 视图统一表达“当前不可操作”的砖块；试玩状态按 Unity 游戏的真实观感明显压暗，解除遮挡后立即恢复。
2. AI 生成不再把五阶段仅作为说明文字，而是用“塔—薄掩体—塔群—深层卡点—释放残局”直接规划坐标。
3. 继续保证固定 7×8 棋盘、精确砖块数和有效层数、同层零面积重叠、图案成对、种子可复现且关卡可完整求解。

## 现状与根因

### 遮挡表现

- `PlaySession` 已正确刷新 `covered` 和 `sideBlocked`，`view-model` 也会输出统一的 `blocked`。
- 2D 主要依赖资源遮罩透明度，3D 的材质颜色仅降到约 78%，两个视图没有共同的明暗标准。
- Unity `LevelSceneWorldTileView` 使用 `CoverDimFactor = 0.58`，即不可操作牌的 RGB 乘 58%，等价在不透明牌面上覆盖 42% 黑色。网页应以此作为试玩基准。

### AI 布局

- 当前五阶段只控制每阶段砖块数、层数和目标压力，没有传入坐标放置器。
- 坐标候选跨越整个 7×8 棋盘，随后全局几何优化又以减少平均遮挡数为唯一主目标，把局部塔体重新打散。
- 现有门禁只覆盖可解性、平均遮挡、重叠比例和开局对子，缺少塔数、大平层、边界/缺口和残局释放检查。

## 方案

采用“结构模板 + 参考样本统计”的混合生成：

- 固定模板负责结构底线：多塔入口、小平台、十字/棋盘缺口、错位台阶、薄掩体连接、受控峰值和残局释放。
- 参考关卡只学习空间统计：塔心、对称倾向、伙伴距离、边界密度和层分布；不复制具体坐标。
- 候选牌对从全部合法锚点组成，但按阶段的活跃塔心、平台半径、塔心复用、同层邻接和伙伴距离排序。
- 禁止全棋盘自由搬移；只保留结构规划器的局部塔体与阶段转折。

此方案比只调随机权重更能保证结构底线，也比复制模板有更高的变化性和可复现性。

## 五阶段空间规则

按实际试玩顺序从高层到低层：

1. **表层塔群**：4–6 个分离入口，开局至少满足难度档的安全对子数；同层分散到多个塔心。
2. **薄掩体**：只连接 2–3 座塔，平台保持窄且有真实缺口，不生成覆盖整个棋盘的大平层。
3. **中层塔群**：重新组合小/中/高塔，塔心产生小幅错位，形成台阶和路线转折。
4. **深层卡点**：收紧到少数高塔核心；高难允许主要路线减少，但必须仍可判断。
5. **释放残局**：减少依赖与平台连接，伙伴距离缩短，压力必须低于深层卡点。

默认结构参考飞书高难矩阵：

- 标准：约 200 张、15 层、2 座高塔与 4–5 个入口区域。
- 困难：约 240 张、可扩展到 30–40 个有效层、3 座高塔与 5–6 个入口区域。
- 目标难度继续由现有五维评分计算，可解门禁保持不变。

## 结构统计与门禁

新增并记录：

- `towerCount`：高层重叠/相邻结构形成的独立塔体数量。
- `platformComponentCount`：所有层的小平台连通分量总数。
- `largestFlatPlatformSize` / `largestFlatPlatformRatio`：最大同层连续平面。
- `boundaryRatio`：同层牌四周暴露边占比，用于识别缺口和大平层。
- `stagePressure`：进入各阶段时剩余牌的开放率与可用对子。
- `releaseDependencyDrop`：深层卡点到释放残局的压力下降值。

生成候选必须满足结构门禁后才进入求解和难度评分；门禁阈值随难度调整，但所有难度都拒绝单一大平层和无释放段的结果。

## 遮挡视觉规则

- 试玩 2D/3D：`covered || sideBlocked` 使用 0.58 亮度；不降低整体透明度，避免背景穿透。
- 编辑 2D/3D：保留较轻的 0.76 亮度，仍能分析层、选择和关系高亮。
- `hiddenPattern` 与翻面保持遮罩语义；遮挡明暗不能覆盖编辑器的选择、错误和关系高亮。
- 槽内牌、已移除牌不保留棋盘遮挡明暗。
- 3D 同时压暗牌面和侧面，并保留真实光照投影；2D 加入内阴影，使“被上层压住”而非“半透明”。

## 验收

- 单元测试验证 0.58 游戏压暗、编辑/试玩差异、解除遮挡恢复。
- 生成器测试验证固定 7×8、精确数量/层数、同层零重叠、成对、可解，以及塔数、最大平层、边界率和释放压力下降。
- 浏览器分别截图验证 2D/3D 试玩的被压砖块和 AI 生成塔群。
- 保持空公开内置库、本地导入学习、LAN 动态关卡和 Unity `_Trash` 功能不回退。
