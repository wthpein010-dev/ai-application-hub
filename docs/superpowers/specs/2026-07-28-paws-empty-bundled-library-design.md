# Paws 关卡编辑器：清空公开内置关卡库

日期：2026-07-28

## 目标

公开网页和 GitHub Pages 不再附带任何工程关卡 JSON。静态关卡目录只保留空索引，首次访问显示明确的空库引导；用户仍可新建、导入本地 JSON、让 AI 学习本地参考、编辑、2D/3D 预览和试玩。

## 边界

- 删除 `projects/paws-level-editor/levels` 中 23 个公开关卡 JSON。
- `levels/index.json` 固定为 `{"defaultFileName":"","levels":[]}`。
- 不读取、移动、删除或修改 Unity 工程的 `EditorLevels` 与 `_Trash`。
- LAN 工作台继续通过服务端读取 Unity 目录，删除与恢复能力不变。
- 浏览器 localStorage 中已有的导入、手工和 AI 关卡继续并入目录。

## 空态

- 真正没有任何目录项且搜索框为空时，关卡库显示“内置关卡库已清空，可新建或导入 JSON。”
- 有关卡但搜索无匹配时，继续显示“没有匹配的关卡。”
- 舞台空态引导桌面用户新建或导入；移动端说明需在桌面端加入关卡。
- 顶部说明改为“内置关卡库已清空”，并明确浏览器本地保存边界。

## AI 行为

- “全部关卡”只学习当前可见且允许学习的浏览器本地/LAN 参考。
- 没有参考关卡时沿用明确拒绝，不伪造或暗中恢复公开内置样本。
- 用户导入参考后即可正常生成。

## 发布验收

- `levels/index.json` 返回 200，默认文件名为空、目录为空。
- 旧的 23 个公开关卡 URL 不再存在。
- 空态、新建、本地导入、保存、删除、AI 生成、2D/3D 和试玩均通过浏览器回归。
- LAN 动态目录、工程回收站测试继续通过。
