# Paws 内网回收站与工程草地还原设计

**日期：** 2026-07-23
**状态：** 已批准（用户已选择 A：内网工作台服务器，并要求直接开发）

## 目标

在不削弱 GitHub Pages 公网演示安全边界的前提下，让同一套最新 Paws 网页编辑器在内网服务模式下直接读写 Unity `EditorLevels`：内置关卡可删除到工程 `_Trash`、可恢复，并让所有已打开的内网页面立即看到目录变化。同时把 2D、3D 和试玩舞台的草地还原为 Unity 工程的真实资源、分布和简化动态。

## 已比较方案

1. **同源内网服务 + 最新网页（采用）**：同一 Node 服务托管当前 `projects/paws-level-editor` 和受限文件 API，页面启动时自动识别内网模式。优点是无跨域、无混合内容问题，AI、3D、编辑与试玩能力保持一致；公网仍自动使用静态浏览器存储。
2. **只增强旧 `sheep` 工作台**：改动较少，但页面已经落后，无法继承当前 AI 生成、固定 7×8、可解门禁、分层检查等能力，长期会形成两套编辑器。
3. **Pages 跨域连接局域网 API**：部署表面简单，但 HTTPS 页面访问 HTTP 内网服务会被浏览器拦截，还会扩大 CORS、私网访问与口令攻击面，因此不采用。

## 运行时边界

- `app.mjs` 启动前探测同源 `/api/health`。响应明确声明 `mode: "lan"` 时使用内网 API，否则使用现有静态 API。
- GitHub Pages 上 `/api/health` 不存在时静默回退，不显示错误，不尝试访问磁盘，也不允许删除内置关卡。
- 内网服务只暴露启动参数指定的关卡、牌图和网页目录；文件名必须是无路径分隔符、无控制字符的 `.json`。
- 读操作无需口令；保存、另存、删除和恢复均需要当前服务会话口令。口令仅存在服务进程内存及 `HttpOnly; SameSite=Strict` 会话 Cookie 中。

## 删除与恢复事务

### 删除

1. 客户端提交 `fileName` 和打开时记录的 `expectedVersion`。
2. 服务端重新计算 SHA-256；版本不一致返回 `409 version-conflict`，不移动文件。
3. 目标名沿用工程现有格式：`<原名>_<YYYYMMDD_HHmmss>.json`；同秒冲突时追加序号。
4. 将 JSON `rename` 到 `EditorLevels/_Trash`。若存在同名 `.json.meta`，一并移动为对应 `.json.meta`，保留 Unity GUID。
5. 任一步失败都尝试回滚已经移动的文件；回滚不完整时返回明确的 `trash-rollback-failed`，不报告成功。

### 恢复

1. 回收站接口只列出 `_Trash` 根目录中的 `.json`，从末尾时间戳推导原文件名，同时读取关卡名称、ID、牌数、删除时间和 SHA-256。
2. 恢复前确认活动目录中 JSON 与 `.meta` 目标均不存在；存在即返回 `409 restore-conflict`，绝不覆盖。
3. JSON 与可选 `.meta` 依次原子移回，失败时反向回滚。
4. 删除或恢复成功后，服务器立即广播目录版本事件。

## 多用户同步

- 内网 API 提供同源 Server-Sent Events 流 `/api/events`。
- 服务自身保存、删除、恢复后立即推送；同时监听 `EditorLevels` 与 `_Trash`，Unity 或资源管理器造成的外部变化经过短防抖后推送。
- 客户端收到事件后刷新活动关卡与回收站清单。
- 当前关卡被他人删除时：无未保存改动则自动回到默认关；有未保存改动则保留内存文档，提示用户另存或恢复，绝不静默丢失。
- SSE 断线使用浏览器原生重连；页面关闭时自动释放连接。

## 页面交互

- 关卡库工具区增加“回收站”入口，显示数量。
- 内网模式下，内置工程关卡和新建/导入/AI 关卡都可删除；公网静态模式维持现有“只能删除浏览器本地关卡”。
- 删除确认文案明确“移动到工程 `_Trash`，可恢复；AI 将立即忘记其结构”。
- 回收站弹窗逐项显示原文件名、关卡名、删除时间和“恢复”按钮；恢复后自动刷新并打开该关。
- 连接状态明确区分“内网工程模式 · 改动同步到所有用户”和“公网演示模式 · 只保存当前浏览器”。

## 草地视觉

- 直接复用 `Assets/Resources/LevelScene/grass.png` 的发布副本，不生成新画风。
- 2D 与试玩：增加独立的透明草地 Canvas；从 94×34 atlas 裁出 `Grass1`（53×29）和旋转存储的 `Grass2`（30×35），按 Spine `grass.json` 的 12 个骨骼位置铺在 `#47BD7F` 舞台上。
- 动画复刻 `Grass`：约每 1.0667 秒执行一次 `scaleY 1 → 1.3 → 0.9 → 1` 的短促伸缩，其余时间保持静止。它在砖块后方、底色上方，不拦截鼠标。
- 3D：用同一 atlas 生成两种透明纹理，在棋盘外围按相同相对分布放置直立双面草簇；沿用相同伸缩曲线，不写深度且不与砖块产生闪烁。
- `prefers-reduced-motion: reduce`、后台标签页和低精度移动端使用静态帧；资源加载失败时退回纯 `#47BD7F`，不影响编辑或试玩。

## 错误处理与安全

- 所有写接口执行同源检查、会话校验、请求体大小限制、路径穿越防护和乐观并发。
- 回收站 ID 仍按安全文件名处理，恢复目标由服务端推导，客户端不能指定任意磁盘路径。
- 文件 API 不跟随目录外路径；静态服务只托管 Paws 页面与所需模块/资源。
- 目录不可读、JSON 损坏、冲突、认证失败和事务回滚失败均使用稳定错误码，UI 显示可操作信息。

## 测试与验收

- 单元测试：文件名与回收站名解析、JSON+meta 成对移动、同秒冲突、版本冲突、目标冲突、各阶段失败回滚。
- HTTP 测试：未认证写入拒绝、登录后删除/列出/恢复、SSE 接收服务写入与外部目录变化、公网静态 API 仍拒绝删除内置关。
- UI 测试：两浏览器上下文即时同步、删除后默认关回退、脏文档保留、恢复并打开、AI 参考数同步更新。
- 视觉测试：2D、3D、试玩桌面与 390px；草地图集裁剪正确、动画有变化、减少动态效果静止、WebGL 无控制台错误。
- 发布前重跑全量 Node 测试、全部 `.mjs` 语法检查、Paws 浏览器 smoke、媒体 proof 录制；推送 `origin/main` 后等待 Pages，再做公网 HTTP 与真实浏览器回归，确认公网仍为静态只读模式。
