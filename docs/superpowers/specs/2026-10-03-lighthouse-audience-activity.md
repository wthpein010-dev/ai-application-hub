# 《灯塔救援队》观众贡献提示规格

状态：依据已确认的完整游戏目标与 2026-09-29 设计规格推进；用户已授权直接完成后续开发与发布。

## 目的

直播画面应让观众看见免费操作确实影响局势，让主播能读出最近一次互动。现有总数与通用反馈保留；增加短时、限量的昵称贡献提示，不改变规则内核、结算或模拟版标识。

## 输入与隐私

- 标准化 `GameEvent` 增加可选 `DisplayName`。规则仍只使用稳定 `UserId` 去重；界面绝不把原始 `UserId` 当昵称展示。
- 昵称仅用于已接受的观众操作：上船、左右投票、修理、照明、点赞与礼物。主播开始、暂停、结束、裁定不进入观众提示。
- 缺失昵称显示“观众”；去除控制字符、换行、格式控制符和富文本尖括号，最多显示 8 个可见文字单元。界面文字关闭富文本解析。

## 画面反馈

- 在现有“每段自带 1 格值守”提示行轮播最近最多 3 条有效观众操作，单条显示昵称与明确动作，例如“海风：修理 +1”。无记录时恢复值守说明。
- 新操作先显示；随后每约 1.6 秒轮到较早操作，记录至多保留 5 秒，避免刷屏。过期、换局、恢复检查点后不显示上一局昵称。
- 当前通用接受/拒绝反馈继续显示结果码的解释；拒绝事件不进入贡献轮播，不改变画面计数。
- 按钮、倒计时和三段第一人称救援画面的位置不变；390px 手机仍可读。

## 验收

- Unity EditMode 覆盖匿名与恶意昵称、接受/拒绝过滤、最多 3 条、过期、换局/恢复清空，验证救援规则不变。
- Windows 和 WebGL 从同一 Unity 源码构建；Windows 全新解压完成一局，桌面与 390px WebGL 操作一局并检查提示无溢出。
- 更新公开视频、规则/主播说明、Hub 版本与 Windows Release，等待精确提交的 Pages 和 CI 成功后核对公网资源。
- 正式抖音 SDK、玩法权限、真实直播间和提审仍是独立外部前提，发布继续明确标记“本地演示”。
