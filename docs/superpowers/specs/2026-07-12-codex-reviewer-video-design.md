# Codex 对话评分工具介绍视频设计

## 目标

为 AI 应用总览中的“Codex 对话评分工具”补充一个可在线打开的中文介绍视频。视频应展示真实使用流程和真实输出结构，让第一次接触工具的用户在三分钟内理解它解决什么问题、如何运行、生成什么结果，以及怎样安全地用于复盘 Codex 协作质量。

## 已确认方案

采用“真实流程演示＋关键结果特写”。视频以工具的真实页面、Windows 启动过程和脱敏后的示例 Excel 为主要画面，不制作只有文字卡片的纯幻灯片，也不保留冗长的命令行等待过程。

## 视频规格

- 画面：1920×1080，16:9。
- 编码：H.264 视频与 AAC 音频，输出 MP4。
- 时长：两至三分钟，硬性上限三分钟。
- 语言：普通话中文配音。
- 字幕：内嵌中文字幕，同时提供 WebVTT 字幕轨道。
- 数据：只使用虚构或脱敏的对话示例，不展示真实用户对话、令牌、路径中的个人信息或其他秘密。
- 节奏：跳过安装与扫描等待，通过剪辑保留必要的状态变化。

## 内容结构

1. **问题与定位**：说明长对话包含大量需求、修改和验证记录，人工复盘困难；工具用于把这些记录转成可检查的评分报告。
2. **启动方式**：展示 Windows 双击运行入口，并简短说明 macOS 可使用源码脚本。
3. **读取与安全**：展示工具定位本地 Codex 会话、读取用户提示，并说明默认隐藏 API key、token 和 password 类敏感内容。
4. **评分过程**：展示提示词清晰度、上下文完整度、可执行性和风险控制等评价维度，以及逐条反馈和建议改写。
5. **结果特写**：展示 Excel 中的“总览”“逐条评分”“会话汇总”“评分规则”四个工作表，强调平均分、主题、问题定位和改写建议。
6. **复盘使用**：展示如何从低分提示中总结可复用的提问方式，并说明报告适合个人复盘和团队规范整理。
7. **结束引导**：提示用户可返回应用集合下载 Windows 包、Mac 源码包或查看说明。

## 画面与素材

- 使用现有 Codex 对话评分工具页面作为开场和结束画面。
- 使用脱敏后的示例输入、工具运行状态和示例 Excel 结果制作核心演示画面。
- Excel 特写应保证工作表名称、分数、反馈和改写建议在 1080p 下清晰可读。
- 使用与“小游戏立项工具”视频一致的深色播放页结构，但文案、封面和配色按 Codex 对话复盘主题调整。
- 视频播放页采用点击后加载，避免主页或视频页初次打开时自动下载完整 MP4。

## 站点接入

- 在 `codex-reviewer` 应用元数据中增加独立 `video` 地址。
- 视频按钮打开 `projects/Codex对话评分工具/视频资源/演示视频.html`。
- 新播放页取代当前占位跳转页，并提供标题、简介、视频播放器、字幕轨道和返回应用入口。
- 保留现有网页演示、Windows 下载和 Mac 下载地址，不改变工具分类和其他卡片信息。
- 对浏览器本地缓存中的旧 `codex-reviewer` 元数据进行视频地址迁移，确保老访客也能看到新入口。

## 生成与维护

- 保存分镜、配音文案和字幕源文件，便于功能更新后重新生成。
- 提供可重复运行的视频生成脚本，统一帧尺寸、配音、字幕烧录和 MP4 编码参数。
- 生成脚本应明确依赖 FFmpeg 和 Windows 中文语音；缺少依赖时给出可读错误。

## 验证标准

- 首页中的 Codex 对话评分工具显示“视频”按钮，且不影响演示和下载按钮。
- 视频页、MP4 和 VTT 在线地址均返回成功状态。
- 视频包含画面与音轨，分辨率为 1920×1080，时长不超过 180 秒。
- 在线 MP4 与仓库中的发布文件一致。
- 字幕与配音覆盖完整演示流程，没有展示真实敏感信息。
- 桌面与窄屏浏览器均能打开播放页，播放器不会造成横向溢出。
- 自动化测试覆盖元数据、缓存迁移、视频页懒加载、字幕引用、视频格式和时长。

## 非目标

- 不修改对话评分算法或 Excel 生成逻辑。
- 不将网页说明页改造成在线评分服务。
- 不上传或处理用户的真实 Codex 对话数据。
- 不重新打包 Windows 或 Mac 下载包，除非验证发现现有包已损坏。
