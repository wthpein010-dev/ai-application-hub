# Paws 专业 3D 检查、Unity 元数据与关卡同步设计

**日期：** 2026-07-22
**状态：** 已确认（用户已授权持续开发、测试和发布）
**适用范围：** `projects/paws-level-editor`

## 背景

当前网页编辑器已经具备安全编辑、2D/3D 共状态试玩、层级截面、AI 生成、同层零重叠、偶数配对与完整可解门禁。继续对照 Unity `SheepLevelEditor` 和运行时后，剩余最影响日常生产的不足集中在三处：3D 只能自由旋转、关卡运行元数据无法直接编辑、公开关卡目录没有持续以 Unity 源目录为权威同步。

## 目标

1. 3D 视图可以快速切换等距、俯视、前视和侧视，并可聚焦选中砖块。
2. 通过层间距控制把多层结构拉开，检查 15 层左右关卡的内部结构。
3. 选中砖块时可看见上层遮挡者、下层受影响砖块和同层左右夹压者；校验错误和警告在 3D 中持续着色。
4. 网页可编辑并往返保留 Unity 运行所需的 `gameLevelOrder`、`cdNum`、`showLayerNum`，且 `levelKey` 与关卡 ID 同步。
5. 公共关卡库严格同步当前 Unity `EditorLevels` 目录，删除已经从源目录移除的旧文件，并把“第二关模板12”的现行文件设为默认。

## 方案

### 3D 关系模型

新增纯函数模块 `core/tile-relations.mjs`：

- `analyzeTileRelations(tiles, selectedUids)` 返回三组关系边：
  - `upper-blocker`：更高层且与选中砖块有正面积相交；
  - `lower-dependent`：更低层且与选中砖块有正面积相交；
  - `side-blocker`：同层、同 Y，锚点位于选中砖块左右各 8 微格。
- 关系只从当前未移除、未进入暂存槽的棋盘砖块派生，不写入 JSON。
- 多选时边去重，避免同一对砖块重复画线。
- `buildIssueSeverityByUid(issues)` 将校验项归并为每张牌的最高严重级别，错误高于警告。

### 3D 展示与控制

`Three3DView` 增加：

- `setCameraPreset("iso" | "top" | "front" | "side")`；相机始终对准当前控制目标，并保持适合当前关卡的距离。
- `focusSelection()`；有选择时聚焦选择包围盒，无选择时回退到适配全关。
- `setLayerSeparation(value)`；值域 0–1，映射为额外的逐层高度，0 保持真实紧凑视图，1 用于最大爆炸检查。
- `setIssues(issues)`；错误砖块红色、警告砖块黄色。
- 关系线：上层遮挡橙色、下层受影响蓝色、左右夹压紫色。只在编辑态且有选择时显示。

着色优先级为：选中 > 错误 > 警告 > 关系对象 > 原有被锁/夹压表现。试玩保持实际游戏皮肤，不显示编辑关系和校验色。

工具栏仅在 3D 编辑态显示紧凑检查区：四个视角按钮、聚焦按钮、层间距滑杆和关系图例。层级截面仍与 2D 共用，不新建第二套层级状态。

### Unity 元数据

内部标准文档新增 `gameplay`：

```js
{
  levelKey: number,
  gameLevelOrder: number,
  cdNum: number,
  showLayerNum: boolean,
}
```

适配规则：

- 从 `designerNote` 读取；缺失时分别回退为 `id`、`1`、`0`、`true`。
- 序列化时写回同名字段，未知字段继续原样保留。
- 修改 ID 时强制 `gameplay.levelKey = id`，避免两处漂移。
- `gameLevelOrder` 为大于 0 的整数；`cdNum` 为不小于 0 的整数，0 表示不限时；`showLayerNum` 为布尔值。
- 新建关和 AI 关补齐 Unity 安全默认结构，包括空的 `blockTypeData`、`levelData`、`goldBlockData` 与 `cakeNum=0`。

属性面板增加“游戏运行”分组，保持表单精简，不暴露暂未被网页可靠解释的复杂数组编辑器。

- GitHub Pages 静态前端不嵌入仓库凭据。内置关卡的服务器删除通过“从 Unity 源目录删除后发布同步”完成；浏览器按钮仍只删除本地学习参考。

## 错误处理

- 无选择时“聚焦”执行全关适配，不报错。
- 相机预设和层间距切换不修改关卡数据，不进入撤销历史。
- 关系目标被层级过滤隐藏时不画对应线；切回全部层后自动恢复。
- 元数据输入非法时拒绝提交并提示，不留下部分修改。
- 同步前默认文件不存在、源目录为空或 JSON 损坏时立即失败，不删除目标目录现有数据。

## 验收

1. 纯函数测试覆盖三类关系、边去重、暂存/删除过滤和问题严重度归并。
2. 3D 四个相机预设、聚焦和 0–100% 层间距均可操作，200 张/15 层关卡无闪烁和控制台错误。
3. 选中一张存在依赖的砖块后可看见正确关系线；错误/警告着色稳定。
4. 元数据编辑、保存、导出、重新导入往返一致，未知字段不丢失。
5. 公共目录与 Unity 源目录文件集合完全一致，默认打开现行“第二关模板12”。
6. 完整测试、桌面/移动浏览器、教程媒体、Pages HTTP 和公网浏览器验收全部通过。

## 非目标

- 不在 GitHub Pages 前端保存 GitHub Token 或实现无认证的远端仓库写入。
- 本批不实现 3D 直接放置、框选或拖动砖块；这些仍在 2D 精确编辑视图完成。
- 不逐帧移植 Unity 特效和 IMGUI 外观。
