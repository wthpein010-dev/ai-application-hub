# 《灯塔救援队》船上视角与风暴表现规格

状态：用户于 2026-10-03 明确要求。此前已授权本项目直接开发并发布，无需逐步确认。

## 目标

三段救援是本局的主要画面时间，应从救援船上的第一人称视角直接看到落难者；航行、集结、选路、冲刺和结算仍用现有俯视航海图。视觉、灯光和音效须共同说明危险与救援进度，保持 390px 手机画面可读和原有规则、操作位置不变。

## 画面与镜头

- `Checkpoint1/2/3` 分别使用三张同风格原创船上视角图。船头与探照灯在近景，单个落难者在中景且是主要视觉焦点。阶段切换时直接切到对应图，辅以短暂亮度过渡；暂停时保留暂停前的镜头，恢复不误播救援反馈。
- 其他阶段保留 `NightSeaV2` 俯视图、船只和待救者位置。结果页仍显示救援人数及结局。
- 视觉层完全受规则快照驱动，不改变事件语义、时长、去重或胜负条件；WebGL 与 Windows 表现一致。

## 风暴与光

- 增加屏幕内循环雨丝、前景水花粒子和随风斜向运动；三段救援逐段增强，航行时较弱。粒子数量固定上限，所有粒子复用，不能每帧分配 Unity 对象。
- 探照灯使用暖色径向光晕，随照明进度增强并轻微扫动；不能把人物或信息栏冲白。随机闪电用固定种子/时间表驱动，包含短促冷白闪光与可见的曲折电光；强度限制在可读范围，暂停时冻结。
- 船体受损保留红色短闪，救人反馈保留金色庆祝；新效果不能覆盖按钮、倒计时或重要文字。

## 声音

- 新增原创程序合成的雨浪循环和雷声，按阶段调节雨浪音量；闪电后播放雷声。现有点击、确认、警告和救援音效继续使用。
- 主播“静音”必须同时关闭天气循环及所有一次性音效；暂停时天气音量降低。WebGL 浏览器音频启动约束按现有按钮交互处理，不自动请求麦克风或播放外部媒体。

## 交付与边界

- 用 Unity EditMode 测试验证镜头阶段、暂停镜头、粒子对象池、静音与资源存在；Windows 全新解压实跑和桌面/390px WebGL 真实浏览器整局复验，截图确认三段船上视角和航行俯视角。
