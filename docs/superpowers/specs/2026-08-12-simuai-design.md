# SimuAI 万物实验室设计规格

日期：2026-08-12
状态：已获用户确认，待实施
目标周期：1–3 天完成首版原型

## 1. 产品定位

SimuAI 万物实验室把适合量化的自然语言问题转换为可以拖动参数、观察曲线并查看计算依据的互动实验。

一句话定位：

> 输入一个“如果……会怎样”的问题，立即得到可以拖动、观察和解释的互动实验。

产品不承诺预测现实，也不把估算包装为科学结论。所有实验必须公开变量、单位、公式、假设和适用边界；无法可靠量化的问题必须降级为推荐相近实验或提示用户补充信息。

## 2. 成功标准

- 观众能在 10 秒内理解“自然语言问题变成交互实验”的核心价值。
- 内置实验无需 API，也能完成从选择问题到拖动参数、图表联动、查看解释的完整闭环。
- 参数改变后，图表、关键指标和结论在当前浏览器帧内同步更新，不再次调用模型。
- 三个主舞台具有足够清晰的视觉差异和演示冲击力。
- 每个输出均标明模型假设和估算属性，不出现无依据的确定性结论。
- API 不可用、输出非法或问题不受支持时，产品仍能给出可理解、可继续操作的结果。

## 3. 首版范围

### 3.1 核心流程

1. 用户输入一个适合量化的问题，或点击示例问题。
2. 本地匹配器先检查是否命中 12 个已验证模板。
3. 未命中时，前端向同源轻量 API 代理提交问题。
4. AI 编译器只返回符合受约束结构的实验说明书 JSON，不返回或执行任意代码。
5. 校验器检查模型类型、参数数量、范围、单位、公式引用和文案长度。
6. 渲染器根据说明书构建参数控件、图表、关键指标、即时结论和解释面板。
7. 用户拖动参数；本地模型引擎重新计算全部结果。
8. 用户可查看公式、假设、适用边界和风险提示。

### 3.2 六类受支持模型

首版模型 DSL 只允许下列类型：

1. `linear`：线性累积、固定速度消耗或增长。
2. `compound`：定期投入与复利增长。
3. `decay`：指数衰减和半衰期模型。
4. `funnel`：多阶段转化漏斗。
5. `inventory`：库存流入、流出与耗尽时间。
6. `payback`：成本、收入、留存或转化共同决定的回本模型。

模型由受信任的本地函数实现。AI 只能选择模型并填写允许的参数，不能注入表达式、JavaScript、HTML 或外部资源。

### 3.3 十二个内置实验

#### 三个主舞台

1. 咖啡因衰减：摄入量、摄入时间、半衰期、观察时长。
2. 小游戏买量回本：每日买量成本、新增用户、留存、单用户广告收益、观察天数。
3. 定期存钱与复利：初始本金、每月投入、年化收益率、年限。

#### 九个次级实验

4. 睡眠债累积与恢复。
5. 体重趋势估算。
6. 阅读或学习进度累积。
7. 销售漏斗转化。
8. 订阅业务增长。
9. 库存消耗与补货。
10. 项目预算燃尽。
11. 活动报名到到场漏斗。
12. 游戏数值成长曲线。

每个模板必须包含稳定 ID、分类、示例问题、参数定义、默认值、合法范围、模型类型、指标定义、图表定义、结论生成规则、公式说明、假设和风险提示。

## 4. 交互与界面

### 4.1 初始页

- 顶部展示产品名、定位和“估算实验，不是现实预测”的简短提示。
- 主输入框允许输入自然语言问题，主按钮文案为“生成实验”。
- 三个主舞台以大卡片展示，九个次级模板按生活科普、游戏产品、商业决策分组。
- 首次打开默认加载“小游戏买量回本”，确保页面不是空白状态。

### 4.2 实验舞台

- 左侧或上方：3–5 个参数滑块；精确值可通过数值输入框修改。
- 中央：主图表，支持折线、面积线或漏斗三种受控表现。
- 右侧或下方：2–4 个关键指标和一段随参数变化的即时结论。
- 参数变化时，数字和曲线使用短促过渡动画，避免整页重建。
- “为什么这样算”抽屉展示公式的人类可读版本、变量说明、假设和适用边界。
- 移动端改为单列：问题、指标、图表、参数、解释依次排列，避免横向溢出。

### 4.3 生成反馈

AI 生成时用“识别问题 → 选择模型 → 生成实验”三阶段状态表现变化过程。若本地模板命中，则快速播放同一过程，不伪称发生了远程 AI 调用。

## 5. 系统结构

### 5.1 前端模块

- `templates`：12 个受信任模板及其关键词、同义词和元数据。
- `matcher`：本地标准化、关键词评分和模板匹配。
- `schema`：实验说明书校验、默认值补全和安全限制。
- `engine`：六类确定性计算模型。
- `presenter`：把模型结果转换为指标、序列和结论。
- `chart`：无任意代码执行的 SVG 图表渲染。
- `ui`：输入、模板库、参数控件、解释抽屉和错误状态。
- `cache`：按规范化问题保存经过校验的实验说明书，不保存 API 密钥。

模块间只传递普通数据对象。计算引擎不依赖 DOM，模板和引擎可独立单元测试。

### 5.2 AI 编译器与代理

轻量代理提供一个同源 `POST /api/compile` 接口：

- 从服务器环境变量读取模型密钥。
- 对问题长度、请求体大小、调用频率和超时时间设上限。
- 使用低成本文本模型和严格 JSON Schema 输出。
- 不记录密钥、完整模型响应或敏感请求头。
- 返回前再次校验结构；非法响应统一转为可识别错误码。

静态部署或无代理环境下，前端继续使用 12 个内置实验和本地匹配器。首版开发可用本地 Node 代理验证联网能力，但公开 GitHub Pages 版本不得内嵌密钥。

### 5.3 实验说明书数据契约

说明书至少包含：

- `version`：固定为首版契约版本。
- `id`、`title`、`category`、`question`。
- `modelType`：六类模型之一。
- `parameters`：3–5 项，每项包含 ID、标签、单位、最小值、最大值、步长和默认值。
- `metrics`：2–4 项，只能引用模型引擎已知输出字段。
- `chart`：受控图表类型、横轴/纵轴标签和受控序列。
- `explanation`：公式说明、变量说明、假设、适用边界和免责声明。
- `source`：`builtin`、`ai` 或 `cache`，用于诚实展示实验来源。

校验器拒绝未知字段引用、参数越界、非有限数值、超长文本、未知模型或任何可执行内容。

## 6. 成本与性能

- 本地模板和命中缓存不调用 API。
- 未命中的问题最多调用模型一次，不进行自动重试风暴。
- 拖动参数只执行本地计算。
- 规范化后的相同问题使用浏览器缓存；缓存只保存通过当前 Schema 校验的数据。
- API 代理设置短超时，并返回明确的可降级错误。
- 首屏不依赖大型框架或远程图表库；首版优先使用原生 ES 模块和 SVG。

## 7. 错误处理与安全边界

### 7.1 降级行为

- API 缺失或断网：提示“当前使用离线实验库”，推荐匹配度最高的三个模板。
- API 超时：保留用户输入，提供“使用相近模板”按钮，不无限自动重试。
- 非法 JSON 或 Schema 不合格：丢弃输出并回退模板，不渲染部分不可信数据。
- 问题无法量化：说明原因，并给出可量化的改写示例。
- 参数输入无效：限制到合法范围，并在控件旁显示说明。
- 计算产生非有限值：停止该次渲染，恢复上一个有效状态并提示调整参数。

### 7.2 高风险主题

- 医疗、投资、法律、安全等主题只允许教育性质的估算模板或拒绝确定性预测。
- 页面统一显示“这是基于公开假设的互动估算，不构成专业建议”。
- 不生成诊断、个股收益承诺、法律结论或安全操作指令。

### 7.3 密钥与代码执行

- API 密钥只存在于代理进程环境变量，不写入前端、仓库、日志或缓存。
- AI 输出永远不通过 `eval`、`Function`、动态模块、`innerHTML` 或脚本标签执行。
- 所有用户及 AI 文本使用文本节点渲染。

## 8. 测试与验收

### 8.1 单元测试

- 六类模型的典型值、边界值、零值和非法值。
- 12 个模板都能通过 Schema 校验并生成有限数值。
- 模板匹配器对每个示例问题命中预期模板。
- 说明书拒绝未知模型、非法范围、未知指标和可执行字符串。
- 缓存只读取当前版本且通过校验的记录。

### 8.2 集成测试

- 从问题输入到实验生成的完整本地流程。
- 模拟有效 AI 响应、非法 JSON、超时、断网和不支持问题。
- 参数变化同步更新图表、指标和结论，且不触发新的网络请求。
- 解释面板完整展示公式、单位、假设和免责声明。

### 8.3 浏览器验收

- 桌面 `1440×900` 和移动端 `390×844` 无横向溢出。
- 三个主舞台均能在 10 秒内进入可操作状态。
- 键盘可操作输入、示例卡片、滑块、数值输入和解释抽屉。
- 控制台错误、未处理 Promise 拒绝和资源 404 为零。
- 页面源码、网络请求、浏览器存储和日志中不出现 API 密钥。

## 9. 明确不做

首版不包含账号、登录、云端保存、多人协作、分享社区、支付、任意代码生成、任意公式解释器、自动联网查证现实数据、医疗或投资预测、桌面安装包和 Hub 正式发布流程。

若首版原型获得认可，再单独设计公开发布、演示视频、下载包或托管代理；这些不属于当前 1–3 天实现范围。
