# 「万象实验室」品牌改名设计

**日期：** 2026-08-12  
**状态：** 已获名称与范围确认，待书面规格复核  
**适用范围：** AI Application Hub 中的 `simuai` 项目、演示页、视频页与教程媒体

## 目标

将产品面向用户的名称从「SimuAI 万物实验室」统一改为「万象实验室」，使品牌名称更自然、更中文化，同时保持现有 30 个实验、交互方式、静态可靠边界和所有公开链接不变。

## 方案选择

采用“只改公开品牌、保留技术身份”的兼容方案：页面、Hub 卡片、教程和用户文档统一显示「万象实验室」；内部项目 ID、目录、查询参数、环境变量和服务端技术标识继续使用 `simuai` / `SimuAI`。

未采用以下方案：

- 不把目录和内部 ID 一并改名，因为这会破坏已有链接、缓存迁移、测试和发布路径。
- 不保留「SimuAI · 万象实验室」双品牌，因为它仍以英文开头，不符合本次中文化目标，也会让不同页面继续出现两套名称。

## 公开内容范围

以下当前内容统一使用「万象实验室」：

- Hub 应用卡片名称，以及旧默认卡片数据的定向迁移结果。
- 演示页的浏览器标题、品牌区、无障碍标签与页脚署名。
- 视频页的标题、主标题、播放器无障碍标签和章节文案。
- 项目 README 的标题与面向使用者的产品称呼；命令、路径和环境变量继续保留技术标识。
- 教程脚本、海报和 MP4 录屏中可见的产品名称。
- 描述当前产品状态的公开兼容性清单。

历史设计规格、实施计划、提交说明及发布审计记录保留当时名称，不追溯改写。运行时为了识别旧默认数据而保留的「SimuAI 万物实验室」字符串属于兼容逻辑，也不能删除。

## 兼容与数据迁移

- 保留内部 ID `simuai`、目录 `/projects/simuai/`、视频与媒体文件路径、npm 脚本名、服务端日志、环境变量和 localhost 代理协议。
- Hub 从本地存储恢复卡片时，仅当名称精确等于旧默认值「SimuAI 万物实验室」才迁移为「万象实验室」。用户自行修改过的名称不覆盖。
- 现有 `#apps` 分类、卡片顺序、“演示 / 视频”两个入口及返回主页目标保持不变。
- 公开版继续完全在浏览器本地匹配 30 个受控实验，不增加网络 AI 调用；相同输入和参数继续得到相同结果。

## 实现与验证

先新增会因旧品牌仍在当前公开界面而失败的测试，再进行最小改名：

1. 更新发布契约，验证 Hub 默认名称为「万象实验室」，旧默认名称能被定向迁移，自定义名称不被覆盖。
2. 更新页面契约，验证演示页和视频页的可见品牌及无障碍名称统一，同时确认内部路径仍为 `simuai`。
3. 更新 README、当前兼容性清单和教程脚本；重新录制 MP4 与海报，避免画面残留旧品牌。
4. 搜索当前产品文件中的旧名称残留，只允许历史文档和明确的兼容迁移常量保留。
5. 运行 SimuAI 聚焦测试、浏览器桌面/手机冒烟、视频媒体契约、Hub 发布审计和全仓回归。
6. 发布到 `wthpein010-dev/ai-application-hub`，等待精确提交的 GitHub Pages 与完整验证工作流成功，再验收 Hub、演示页、视频页和真实视频播放。

## 验收标准

- 普通用户在 Hub、演示页、视频页、海报和视频画面中只看到「万象实验室」，不再看到旧公开品牌。
- 旧公开 URL 全部继续有效，内部 ID 和静态可靠行为不变。
- 旧默认名称会自动迁移；用户自定义名称保持原值。
- 30 个实验、六个分类、九种模型和五种图表模式均无功能回归。
- 桌面与手机页面无横向溢出、控制台错误或资源加载错误；视频为浏览器兼容 H.264、时长不超过 4 分钟、字幕保持单行。
- GitHub Pages 对最终 `main` 精确提交部署成功，公网内容与该提交一致。
