# Paws 模板塔群生成与受压视觉设计

日期：2026-07-29

## 目标

- 试玩时，普通被上层覆盖或被左右夹住的砖块按 Unity `CoverDimFactor = 0.58` 压暗，并用内阴影和上层投影表达受压关系。
- `presetColorType = 3` 的盲盒平铺下层使用背面视觉表达不可见信息，不再叠加普通受压黑罩；上层移除后自动翻开，再次受压时自动翻回。
- AI 生成不再把每层平均铺满棋盘，而是学习第二关参考关卡的逐层砖数、局部连通块、塔链、缺口、盲盒平铺栈和随机类型比例。
- 保持固定 7×8 棋盘、精确砖数和有效层数、总数偶数、同层零面积重叠、随机类型全局成对且试玩分配可解。

## 模板学习模型

每个参考关卡提取：

- `layerTemplates`：每层的归一化深度、砖数、坐标轮廓、连通块和盲盒语义。
- `layerCountSequence`：由低到高的非均匀砖数序列。
- `typeRatios`：`type=-1`、`type=0` 与固定图案占比。
- `blindStacks`：连续层上 `presetColorType=3` 的下层以及 `moldType=2` 的栈顶。
- 既有塔心、边界率、平台和遮挡统计继续用于质量门禁。

合并学习结果保留多个模板样本，不把所有层平均成一个分布。生成时先选择与目标砖量、层数最接近的参考模板，再将其逐层砖数序列重采样到目标层数，并按目标总量做确定性增减。这样可以保留“少数厚平台 + 多个薄塔层”的节奏。

## 生成流程

1. 按目标难度建立五阶段预算：表层塔群、薄掩体、中层塔群、深层卡点、释放残局。
2. 从参考模板选择连续层轮廓，并用镜像、180° 旋转和安全平移产生变化。
3. 每层只在模板局部轮廓及其邻域补点；禁止同层面积重叠，单层占板比例不得退化成大矩形。
4. 标准与困难档放置 2–4 条盲盒平铺栈；下层为 `moldType=1/presetColorType=3`，栈顶为 `moldType=2/presetColorType=1`。
5. 第二关风格以 `type=-1` 为主体；只要求 `type=-1`、`type=0` 和固定类型在全关成对，不再错误要求每层成对。
6. 试玩分配对非第一关也执行多种子可解重试，返回的具体图案始终两两出现。

## 难度结构

- 约 60 分：4–5 个入口区，两条可恢复路线，盲盒栈较短，深层卡点后较早释放。
- 约 80 分：2 座高塔与约 4 座低塔，中后期收紧到一条主要路线，盲盒局部堆叠更深，但仍保留可识别缺口。
- 约 90 分以上：多塔交叉与分区盲盒，只提高局部依赖链深度，不通过铺满整张棋盘制造伪难度。

## 验收

- 单元测试覆盖普通受压 0.58、盲盒背面不重复压暗、盲盒动态翻面。
- 200 张 / 15 层生成结果以 `type=-1` 为主体，逐层砖数明显非均匀，存在塔、缺口和盲盒栈。
- 多难度、多布局、多种子生成无同层重叠，随机分配后每种图案为偶数且求解器可清空。
- 浏览器分别检查 2D/3D 试玩的受压阴影与生成轮廓，再完成 GitHub Pages 公网验收。
