# 砖块小人图鉴与随身小物市场联动设计

## 目标

把现有 `brick-character-copy-preview` 升级成可公开访问的游戏式“砖块小人图鉴”，并从“随身小物交易市场”提供直接入口。网页用于在浏览器中快速检查 45 个正式角色的名字、获取文案和图鉴描述，尤其要暴露换行、溢出和孤行标点等问题。

## 内容权威

唯一正式数据源是本机已确认的 PawsHomeClient Unity 工程，通过 `PAWS_HOME_CLIENT_ROOT` 传给同步器：

- `cfg_gdblockskin.json` 决定可展示角色、`Stringsequence` 顺序及三类文案键。
- `cfg_gdblock.json` 决定 `block/body/head/dress` 贴图组合。
- `cfg_gdlanguage.json` 的 `zh` 字段提供最终中文文案。
- `Textures/Skin/{block,body,head,dress}` 提供角色分层贴图。
- `UI/AtlasSystem/Sprites/Atlas1` 提供图鉴框、标题、收藏和按钮素材。

同步结果必须恰好包含 `Show == "1"` 的 45 个角色，并按 `Stringsequence` 升序。网页和测试不重复手写角色数据，避免 Unity 配置与公开站点漂移。

## 信息架构

`projects/brick-character-copy-preview/index.html` 是默认图鉴入口。原 20 角色表格完整保存在 `copy-review.html`，作为“文案校对（旧版）”二级入口，并保留其浏览器本地换图能力。

图鉴页顶层导航包含：

- 返回 AI Application Hub。
- 图鉴主页（当前页）。
- 文案校对（旧版）。
- 随身小物交易市场。

小物市场页头增加“砖块小人图鉴”入口。两页互相跳转时不改变市场主题、排序、拖拽或本地编辑状态。

## 图鉴列表

默认所有 45 个角色均为已解锁状态，显示 `已收集：45/45`。

- 桌面逻辑尺寸遵循 Unity：3 列 × 4 行、每页 12 个、单卡 170×180、名字字号 22。
- 共 4 页，最后一页 9 个角色。
- 支持上一页、下一页、搜索、显示收藏、批量收藏状态。
- 角色卡使用正式分层贴图组合，保持透明像素、居中、`object-fit: contain`，不做有损拉伸。
- 首次进入格子逐个出现，翻页按行出现；尊重 `prefers-reduced-motion`。
- 点击或键盘激活任意角色后打开详情。

## 详情与文案检查

详情覆盖在图鉴列表上方，保持兰湖稿的舞台聚光、红色名称条、中央角色、左右切换、收藏、装扮预览和分享视觉。

核心排版严格映射 Unity：

- 描述框逻辑尺寸 464×196。
- 描述文字逻辑宽 420、高度至少 126、字号 28。
- 内容超出默认高度时，框只向下扩展。
- 文案来源是 `GDBlockskin.GalleryDesc`，不得误用 `UnownedDesc`。
- 上一位/下一位跨页连续切换；关闭详情后回到对应页和卡片。

右侧（窄屏改为详情下方）提供检查面板：

- 名称：3–5 个中文视觉位置。
- 获取文案：最多 15 个视觉位置。
- 图鉴描述：建议每行最多 12 个视觉位置，最多 3 行。
- 同时显示浏览器真实渲染行数、是否横向/纵向溢出、是否存在行首标点或单字孤行。
- 超限和异常使用文字标签与颜色共同表达。

中文字符按 1 个视觉位置计算，ASCII 字母、数字和半角符号按 0.5 个计算；统计函数必须独立测试。

## 数据与素材同步

新增 `scripts/sync-brick-gallery-from-unity.mjs`：

1. 必须接受 `PAWS_HOME_CLIENT_ROOT`；未提供时明确失败，不把任何本机绝对路径写进仓库。
2. 读取三份 JSON，解析语言键并生成 `data/characters.json`。
3. 复制 45 个角色实际引用的分层 PNG 和必要 UI PNG，不复制 `.meta`、`Thumbs.db` 或未引用资源。
4. 校验 45 个唯一角色、连续 `sequence`、所有语言键可解析、所有非空贴图存在。
5. 输出稳定排序和稳定 JSON，重复执行不得产生无意义差异。

公开页面只消费同步后的仓库文件，不读取用户本机路径，也不暴露该路径。

## 视觉与响应式

主体保持 750 宽竖屏游戏舞台的比例和兰湖稿结构：白色粗描边图鉴窗、后台灯架、彩色聚光、红色角色标题、灰白文案框。桌面端在舞台右侧显示检查面板；移动端按比例收缩游戏逻辑尺寸并把检查面板放在下方，不产生页面横向滚动。

角色采用轻微待机浮动，打开详情时有聚光和缩放入场。收藏按钮、分页和卡片均有清晰 hover/focus/pressed 状态。

## 发布与媒体

- Hub 卡片仍使用项目 ID `brick-character-copy-preview`，名称更新为“砖块小人图鉴与文案校对”，位于小物市场之前。
- 更新 Hub 展示图、教学视频、海报、字幕和视频说明，使其展示默认图鉴、打开详情、跨角色检查和市场跳转。
- 教学视频为 H.264、1280×720、30–60 秒、单行中文字幕。
- 页面通过 GitHub Pages 公开访问；永久修改继续通过公开 GitHub 仓库完成，浏览器旧版换图仍只保存在本地。

## 验收标准

1. 数据文件恰好包含 45 个角色，名称顺序与 Unity `Stringsequence` 一致，所有文本和贴图路径可解析。
2. 默认显示图鉴而非表格，桌面每页 12 格；首次打开任意角色可见详情，上一位/下一位跨页正确。
3. 所有角色默认解锁；搜索、分页、收藏、批量收藏和关闭返回均可用。
4. 详情的名称、获取文案、图鉴描述与 Unity 完全一致；检查面板能标记超长、溢出和不良换行。
5. 旧版 20 角色文案校对页及本地换图功能仍可用。
6. 小物市场出现图鉴入口，原有主题 A、白昼模式、价格开关、排序、编辑和 Apple 式跨行拖拽测试继续通过。
7. 1440×900、750×1334、390×844 均无横向溢出、资源 404、控制台错误或明显变形。
8. Hub 展示图和教学视频反映新体验；GitHub Pages 的 Hub、图鉴、旧版校对、市场、视频和媒体均公开可访问。
