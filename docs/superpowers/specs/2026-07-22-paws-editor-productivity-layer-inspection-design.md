# Paws 网页编辑器正确性、效率与分层检查设计

**日期：** 2026-07-22  
**状态：** 已确认（用户已授权代理自主完成设计、开发、发布和验收）  
**适用范围：** `projects/paws-level-editor`

## 背景与目标

网页编辑器已经具有关卡目录、本地 JSON 导入、浏览器保存、AI 生成、2D/3D、基础编辑和试玩，但它还不是一个足够可靠的日常关卡制作工具。本轮对照 Unity 工程中的 `SheepLevelEditor`、运行时遮挡/配对规则和当前网页实现，补齐会直接影响关卡正确性、编辑效率、3D 检查和成果回流的高价值能力。

目标不是把 7,000 多行 Unity IMGUI 控制器原样搬进网页，而是在现有模块边界内实现以下闭环：

1. 新放置、拖动、粘贴和层级调整不会悄悄制造越界或同层面积重叠。
2. 策划可以用复制、剪切、粘贴、复制副本、微移和层级微调完成高频编辑。
3. 2D/3D 都能按层截面或单层检查，并正确显示遮挡、夹压和隐藏图案状态。
4. 3D 删除工具实际可用，工具文案与行为一致。
5. 修改后的关卡可以一键导出为保留未知字段的 Paws JSON，回到工程继续使用。
6. 新建关、缺省适配和棋盘设置与 Unity 当前 7×8 默认及尺寸边界一致。

## 现状审计

### 已有且保留

- 双格式 Paws JSON 适配，优先读取 `designerNote.levelData`，序列化时同步顶层 `tiles` 和分层数据。
- 未知顶层字段和 `designerNote` 字段保留。
- 内置 30 关、本地导入、浏览器保存、删除本地参考、AI 实时学习/遗忘。
- 2D/3D 共状态试玩、随机图案成对分配、翻转、双暂存槽和简化特效。
- AI 固定 7×8、偶数牌数、逐层/全局偶数图案、同层零重叠和确定性可解门禁。
- 撤销/重做、点选、Shift 累加、Alt 取消、框选、拖动、放置、删除和属性编辑。

### 已确认不足

1. `Three3DView` 没有接收当前工具和删除回调；选择“删除”后点击 3D 砖块不会删除。
2. 编辑态没有计算覆盖状态，2D/3D 都不能可靠显示被上层遮挡、左右夹压或 85% 覆盖隐藏图案。
3. 放置和移动只执行坐标变更，不检查棋盘边界与同层面积重叠；多选绝对改 X/Y 还会把多张牌压到同一点。
4. 新建关和适配器缺省仍使用旧的 8×10，而 Unity 当前缺省为 7×8。
5. 修改棋盘宽高不会原子同步 `gridUnit`，也不阻止把现有砖块裁到棋盘外。
6. 没有层级截面/单层检查；15 层左右关卡在 3D 中难以定位内部结构。
7. 缺少 Unity 编辑器已有的高频命令：全选、复制、剪切、粘贴、复制副本、方向键微移、PageUp/PageDown 调层、保存和试玩快捷键。
8. 当前快捷键分派没有排除 Ctrl/Meta；例如 Ctrl+D 可能切到删除工具，Ctrl+S、Ctrl+A、Ctrl+F 仍触发浏览器默认行为。
9. 浏览器保存后没有导出入口，网页修改无法顺畅回到 Unity 工程。
10. 校验项只是文字，不能一键选中问题砖块；非 AI 历史关的同层部分重叠完全不可见。

## 方案比较

### 方案一：完整移植 Unity 编辑器

覆盖平铺、皮肤、翻转、地图配置、层级查找、导航历史、热键改键和全部对话框。优点是功能最全；缺点是网页复杂度、维护成本和视觉密度过高，且大量 Unity 专属能力在 GitHub Pages 上没有等价后端。

### 方案二：只修 3D 删除和旧默认值

改动小、风险低，但几何错误、内部层检查、编辑效率和成果回流仍然没有解决，不能达到“足够好”的目标。

### 方案三：高价值能力对齐（采用）

保留当前三栏布局和静态站点架构，新增纯函数几何/快捷键模块，在控制器层组织编辑命令，在两个渲染器中共享覆盖与层级过滤状态。它覆盖日常关卡制作的关键闭环，同时避免把低频 Unity IMGUI 细节全部搬入网页。

## 详细设计

### 1. 编辑几何门禁

新增 `core/editor-geometry.mjs`，作为网页编辑操作的单一几何规则来源：

- 棋盘范围为 `width * 8` × `height * 8` 微格。
- 坐标和层级必须是整数；层级至少为 1。
- 砖块边缘相接合法，正面积相交才算重叠。
- 新放置从用户选择层开始向上寻找第一个无同层面积重叠的位置；若越界则拒绝。
- 移动、粘贴、复制副本和层级微调先生成完整候选布局，再原子校验；失败时不写历史、不改变选择，并给出明确提示。
- 历史导入关不自动改层，避免静默改变既有关卡；新编辑操作不能新增同层重叠。

棋盘宽度限制为 4–16，高度限制为 4–20，与 Unity `SheepBoardLayout` 一致。修改宽高时同时更新 `gridUnit=sheep_<宽>x<高>_mini8`；若新尺寸容不下当前砖块，拒绝修改并指出原因。

### 2. 高频编辑命令

新增 `ui/editor-shortcuts.mjs`，把键盘事件归一化为语义命令，控制器执行命令。工具单键只在没有 Ctrl/Meta/Alt 修饰时生效。

支持：

- `Ctrl/Meta+S` 保存，`Ctrl/Meta+Shift+S` 另存为。
- `F2` 导入 JSON，`F5` 编辑/试玩切换。
- `Ctrl/Meta+A/C/X/V/D` 全选可见、复制、剪切、粘贴、复制副本。
- 方向键按当前吸附步长微移，Shift+方向键按 8 微格移动。
- PageUp/PageDown 将选择整体上移/下移一层。
- `[`/`]` 切换观察层；`L` 在全部、截层、单层之间切换。
- 原有撤销、重做、删除、Escape、工具键和适配视图继续保留。

剪贴板只保存在当前编辑器会话，不读取系统剪贴板。粘贴/复制副本为砖块生成新 UID，并从右、下、左、上及对角方向按吸附步长寻找第一个合法偏移。

### 3. 层级观察

控制器维护 `{ mode: "all" | "through" | "single", layer }`：

- `all`：全部层。
- `through`：显示 1 到当前层，用于从顶部逐层剥离检查内部结构。
- `single`：只显示当前层，用于检查同层分布与重叠。

舞台工具栏提供精简的模式按钮、减层、当前层和加层，不新增侧栏。2D 和 3D 渲染器接收同一过滤状态；试玩始终显示全部层，不受编辑观察状态影响。全选和框选只作用于当前可见砖块，校验问题定位会自动切到能看到目标的层。

### 4. 覆盖状态与 3D 行为

编辑态复用 `computeCoverage` 计算：

- 任意上层面积交叠即 `covered`。
- 同层左右各有一块即 `sideBlocked`。
- 上层并集覆盖至少 55/64 微格即 `hiddenPattern`。

2D 和 3D 都使用这些派生状态，但不把运行时字段写入 JSON。3D 视图新增 `setTool`、`setLayerView` 和删除回调；删除工具点击砖块立即执行可撤销删除。3D 画布显示简短操作提示，选择仍保留轻微抬升反馈。

### 5. 校验与问题定位

扩展静态校验：

- 棋盘尺寸、`gridUnit`、随机图案范围、X/Y/层级整数性。
- 重复 UID、越界、无效类型、奇数总数和奇数图案组。
- AI 同层面积重叠为错误；历史/手工关同层面积重叠为警告，保证兼容同时让风险可见。

属性面板按错误/警告展示校验项。带 `tileUids` 的校验项可点击：选中问题砖块、切换到合适观察层并适配视图。保存仍只被错误阻止，警告不破坏历史关兼容。

### 6. JSON 导出与默认值

属性面板增加“导出 JSON”。导出调用现有 `serializeLevelDocument`，文件名优先使用当前关卡文件名，否则生成安全默认名；导出不改浏览器保存状态。若存在错误，允许导出草稿但明确提示。

适配器从 `designerNote.widthNum/heightNum` 读取尺寸；缺失时尝试解析 `gridUnit`；仍缺失时使用 7×8。新建关直接使用 7×8。属性面板把 `gridUnit` 显示为棋盘尺寸的只读派生值，避免双来源漂移。

## 数据流与模块边界

1. 视图产生点选、放置、移动或删除意图。
2. 控制器调用纯函数几何门禁生成合法命令或拒绝原因。
3. `EditHistory` 原子执行命令，随后重新校验并刷新两个视图共享的状态。
4. 视图从文档派生覆盖状态和层级可见集合，不修改源文档。
5. 保存写浏览器本地记录；导出生成同一序列化 JSON 的本地下载。

纯函数模块不访问 DOM、存储或网络，便于单元测试。控制器不复制覆盖算法；2D/3D 不自行决定编辑是否合法。

## 错误处理

- 非法编辑操作通过短提示说明“越界”“会造成同层重叠”或“层级不能低于 1”，不产生撤销记录。
- 导出 Blob/下载创建失败时保留当前文档并提示，不改变保存状态。
- 层级过滤在关卡切换、删除砖块或撤销后自动钳制到现有最大层。
- 3D WebGL 不可用时维持现有错误处理，2D 仍可编辑和导出。

## 测试与验收

### 单元测试

- 棋盘尺寸解析/构建、边缘相接、面积重叠、自动找层、移动门禁和粘贴偏移。
- 快捷键修饰规则和所有高频命令映射。
- 7×8 默认、`gridUnit` 同步、校验错误/警告与历史兼容。
- 覆盖派生状态和层级过滤。

所有生产代码遵循测试先行：先运行新增测试观察预期失败，再实现最小代码并复跑。

### 浏览器验收

1. 默认工程关正常打开，2D/3D 无控制台和网络错误。
2. 编辑态可看到遮挡/夹压状态；层级模式在 2D/3D 显示同一集合。
3. 3D 删除可撤销；复制、粘贴、复制副本、微移和调层均保持棋盘内且不新增同层重叠。
4. 试图越界或制造同层重叠时操作被拒绝且文档不变。
5. 新建关为 7×8；缩小棋盘导致越界时被拒绝。
6. 导出文件可重新导入，未知字段、砖块数量、棋盘、层级和类型往返一致。
7. 200 张、15 层 AI 关仍为同层重叠 0、图案偶数、100 步可解并实际通关。
8. 390×844 继续保持只读试玩、无横向溢出。

## 非目标

- 不在静态 GitHub Pages 中嵌入 GitHub Token 或实现无后端的远端仓库写入。
- 不移植 Unity 的 Excel、地图上传、包导出和 IMGUI 热键自定义。
- 不实现完整平铺扇形生成器；本轮优先保证已有放置、复制和移动正确。
- 不追求全部游戏特效逐帧一致，继续保持用户允许的简化动画。
