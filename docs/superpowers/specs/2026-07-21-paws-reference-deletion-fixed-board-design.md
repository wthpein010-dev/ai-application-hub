# Paws AI 参考关卡删除与固定 7×8 棋盘设计

日期：2026-07-21

状态：已批准

## 目标

让浏览器导入、手工新建和另存的本地关卡真正参与 AI 参考统计，并允许用户删除所有非内置本地关卡。删除后，下一次 AI 生成必须从当前参考清单重新计算，不能继续使用已删除关卡的结构统计。

所有 AI 生成关卡必须使用固定的 7×8 棋盘：不仅 `designerNote.widthNum/heightNum` 与编辑器面板为 7×8，所有砖块锚点也必须位于对应坐标边界内。

## 范围与术语

- 内置关卡：随公开站点发布、在 `levels/index.json` 中登记的 30 个工程关卡。
- 本地关卡：保存在当前浏览器 `localStorage` 中的非内置关卡，包括导入、手工新建、另存副本和 AI 生成结果。
- 学习参考：AI “全部关卡”模式实际加载并汇总统计的关卡。
- 当前关卡模式：用户明确选择只参考当前打开的关卡；即使当前关卡是 AI 生成结果，也尊重这一显式选择。

本功能不删除或修改发布目录中的内置 JSON，不向 Unity 工程写入数据，也不引入外部模型或服务器训练状态。

## 参考关卡分类

本地保存记录新增来源分类：

- `import`：从本地 JSON 导入。
- `manual`：新建、编辑后另存或普通本地副本。
- `ai`：由 AI 生成器创建。

AI “全部关卡”参考范围为：

1. 所有内置关卡，包括其当前浏览器本地覆盖版本。
2. 所有来源为 `import` 或 `manual` 的非内置本地关卡。
3. 排除来源为 `ai` 的非内置关卡，防止生成结果反复进入训练样本造成结构收敛或偏移。

兼容旧浏览器记录：若本地记录没有来源字段，则检查关卡 `designerNote.aiGeneration`。存在该字段时归为 `ai`，否则归为 `manual`，从而让历史导入关卡仍可参与学习。

## 删除交互

关卡库操作区增加“删除本地”按钮：

- 仅当当前关卡是非内置、本地保存的关卡时启用。
- 内置关卡不可删除；内置关卡的浏览器覆盖继续使用“恢复内置”。
- 新建但尚未保存的临时文档不属于本地清单，不显示为可删除。
- 删除前显示一次确认，明确“无法撤销，AI 下次生成将不再学习这关”。
- 删除成功后清空当前编辑/试玩状态，刷新关卡清单并自动打开目录默认关卡。
- 成功提示包含删除文件名和新的学习参考数量。

移动端维持只读试玩，不显示或启用删除操作。

## 存储与错误处理

静态 API 增加 `deleteLevel(fileName)`：

1. 校验安全文件名。
2. 读取内置索引；若文件属于内置关卡，返回 `cannot-delete-bundled`。
3. 确认浏览器本地记录存在；不存在时返回 `local-level-not-found`。
4. 删除记录键，并从 `local-files` 清单移除文件名。
5. 删除记录和写回清单必须使用同一份快照做失败补偿；任一步失败都恢复删除前状态。

如果删除已成功但后续目录刷新或默认关卡打开失败，控制器保留明确错误提示，不谎报关卡仍存在；再次刷新时应从真实存储状态恢复。

## 无缓存重新学习

系统不持久化合并后的统计或模型。每次点击 AI 生成时：

1. 从最新关卡清单选择符合规则的参考条目。
2. 重新加载这些关卡文档。
3. 重新执行 `extractLevelStatistics` 和 `mergeLevelStatistics`。
4. 使用本次新统计生成候选。

因此删除参考关卡后不需要额外的后台训练任务或“清空模型”按钮；下一次生成天然完成重新学习。控制器不得缓存已加载的参考文档跨生成复用。

## 固定 7×8 棋盘

生成器定义唯一棋盘常量：

- 宽度：7 格。
- 高度：8 格。
- 砖块逻辑尺寸：8 坐标单位。
- 合法锚点：`0 <= x <= 48`、`0 <= y <= 56`。

生成时仍可学习参考关卡的归一化中心、对称、偏移和重叠倾向，但必须把这些比例映射到固定 7×8 输出空间。不得按参考样本平均尺寸或目标层数把棋盘放大到 10×12、12×16 或其他尺寸。

生成结果必须同时满足：

- `document.board.width === 7`、`document.board.height === 8`。
- 序列化后的 `designerNote.widthNum === 7`、`heightNum === 8`。
- 所有砖块完整落在棋盘锚点边界内。
- 继续满足现有重叠预算、同坐标堆叠深度、开局对子、合法性、目标难度和确定性可解检查。

若指定数量、层数和难度在最大候选次数内无法于 7×8 棋盘生成合法可解结果，返回明确错误；不得静默扩大棋盘或输出越界关卡。

## 测试与验收

### 静态 API

- 可删除非内置本地记录，并同步更新清单。
- 拒绝删除内置关卡和不存在的本地关卡。
- 记录删除失败或清单写回失败时恢复原记录与清单。
- 历史无来源记录能按 `aiGeneration` 正确推断来源。

### 控制器与 AI 参考

- 删除按钮只对当前非内置本地关卡启用。
- 删除当前关卡后自动打开默认关卡。
- “全部关卡”加载内置、导入和手工本地关卡，排除 AI 生成关卡。
- 删除一个学习参考后，下一次加载的参考数量和文档集合立即变化。
- “当前关卡”模式仍允许显式参考当前 AI 生成关卡。

### 生成器

- 简单、标准、困难与三种布局均输出 7×8 元数据。
- 所有生成砖块坐标位于 `x=0..48`、`y=0..56`。
- 重点基线 `200 张 / 15 层 / 60 分` 可解，并继续满足现有防大面积重叠规则。
- 相同种子仍确定性一致，不同种子保持布局变化。

### 浏览器

- 导入关卡后能在清单中看到并参与 AI 参考计数。
- 删除后关卡立即消失，刷新页面后不会恢复。
- 删除后生成报告中的参考数量减少，且无控制台、HTTP、页面或请求错误。
- 桌面端操作无横向溢出；移动端维持只读且不暴露删除入口。
