# 随身小物交易市场公开版设计

**日期：** 2026-08-28  
**状态：** 已批准实施  
**公开位置：** AI Application Hub「工程在线体验」集合末尾  
**项目 ID：** `trinket-market`

## 目标

把已确认的“随身小物交易市场”效果稿开发成可公开访问、可编辑、可扩展的纯网页工程，并发布到 `wthpein010-dev/ai-application-hub` 与 GitHub Pages。页面以稳定物品 ID 承载当前 `J:\美术资源\动画资源\角色动画\hand` 中的 11 张随身小物素材，为后续后端按 ID 上报获得次数预留清晰接口。

## 产品边界

- 产品是收藏品展示与统计市场，不提供真实交易、充值或提现。
- 默认显示全服获得数量与数量排名；“参考估值”默认关闭，开启后才显示价格与涨跌幅。
- 默认使用已确认的方案 A“暗夜藏品所”，并支持切换其他配色。
- 桌面默认 8 列、宽屏 9 列，736px 为 6 列，360px 为 3 列；图片按透明像素视觉中心居中，显示尺寸约 163px。
- 拖拽采用苹果 App 桌面式实时让位：跟手浮层、源位置留空、经过目标时相邻卡片实时位移、松手吸附；不允许首卡重影。
- 不建设共享写入后端。任何访客都能在浏览器内编辑名称、拼音、稀有度、数量、参考估值、涨跌幅和图片，结果仅保存在该访客浏览器；支持 JSON 导入/导出和恢复官方数据。
- 页面提供公开 GitHub 源码与编辑入口。需要永久修改公开版本时，访客通过 Fork、网页编辑或 Pull Request 贡献，不允许匿名访客直接改写 `main`。

## 页面与交互

### 首屏

首屏直接呈现标题“随身小物交易市场”、数据更新时间、总获得次数、已收录物品数、参考总估值占位，以及搜索、排序、排序方向、估值开关、配色切换和编辑模式入口。主要网格必须在首屏可见，不放营销 Hero。

### 物品网格

每张卡片固定使用 `HAND-0001` 形式的公开 ID，显示稀有度、居中小物图、中文名、涨跌幅、全服获得数量和数量排名。估值关闭时价格区域不存在可见人民币金额；开启时改为单件参考估值和参考总估值。排序支持手动、ID、中文名拼音、获得数量，数量方向可高到低或低到高切换。

### 访客编辑

点击“编辑物品”进入编辑模式，卡片显示编辑入口。编辑对话框允许修改字段并替换本地图片；图片仅接受 PNG/JPEG/WebP、最大 8 MB。编辑后立即重绘并持久化到 `localStorage`。工具栏提供导入 JSON、导出 JSON、恢复官方数据和 GitHub 源码入口。输入错误必须给出明确中文错误，不静默丢弃。

### 数据接口

官方数据存放在 `projects/trinket-market/data/items.json`。每条记录包含：

```json
{
  "id": 1,
  "name": "便携冰水壶",
  "pinyin": "bianxiebingshuihu",
  "rarity": "常见",
  "acquired": 18342,
  "value": 12.8,
  "change": 2.4,
  "image": "./assets/items/hand_1.png"
}
```

页面公开 `window.TrinketMarketAPI.setAcquisitionCounts(counts)`，参数为 `{ "1": 20000 }` 或同义数字键对象，只更新已存在 ID 的 `acquired` 字段并重新计算排名。页面同时监听 `trinket-market:counts` 自定义事件，读取 `event.detail` 作为同一结构。非法、负数、未知 ID 不进入官方视图。

## 技术结构

- `projects/trinket-market/index.html`：语义结构、统一返回主页按钮、工具栏、网格、编辑对话框。
- `projects/trinket-market/styles.css`：主题变量、响应式网格、拖拽动效和编辑状态。
- `projects/trinket-market/app.js`：数据加载、排序、拖拽、编辑、导入导出、本地存储和后端接口。
- `projects/trinket-market/data/items.json`：官方 11 项数据。
- `projects/trinket-market/assets/items/`：原始 PNG 副本，不把本机路径写入网页。
- `projects/trinket-market/video/`：统一播放器页、H.264 教程、单行中文字幕与封面。
- `assets/hub-showcase/trinket-market.webp` 与 `hub-project-media.js`：Hub 真实页面展示图。
- `app-20260706-restore-games.js`：在工程体验集合末尾注册项目，仅显示“演示 / 视频”。

## 视觉与动效

- 沿用效果稿的暗色玻璃与收藏品仓库语言，正文和物品信息字号不低于已确认值：名称 12px、标签 9px、主要数值 12px、ID/稀有度 8px；移动端不再缩小关键文字。
- 图片不进行插值放大预处理，浏览器使用原 PNG，并避免 `image-rendering: pixelated`。
- 拖拽只在开始和结束创建/移除浮层；网格内重排使用 DOM 移动与 FLIP transform 合帧，每次跨行悬停最多产生 2 次 childList 节点变更。
- 遵循 `prefers-reduced-motion`，减少动效时关闭过渡但保留完整功能。

## 错误与持久化

- 官方 JSON 加载失败时显示错误面板和重试按钮。
- 本地数据结构或导入 JSON 不合法时拒绝覆盖现有数据。
- `localStorage` 不可用或空间不足时继续保留当前会话状态，并显示“未能保存到浏览器”的提示。
- 本地图片使用 IndexedDB 保存，避免大图写入 `localStorage`；恢复官方数据时只删除本项目命名空间。

## 测试与发布

- Node 静态测试验证 11 个唯一 ID、素材存在、Hub 元数据、工程集合末尾、仅演示/视频、统一子页和视频页契约。
- Playwright 验证 1440/1024/736/390/360px，无横向溢出；默认方案 A、默认估值隐藏、11 图居中、排序、跨行拖拽、编辑持久化、图片替换、JSON 导入导出和后端计数接口。
- 教程视频为 H.264、1280×720、时长不超过 4 分钟；字幕任一时刻只显示一行。
- 发布前运行 Hub 全量静态测试、发布审计和浏览器冒烟；推送 `main` 后等待精确提交的 GitHub Pages 与验证工作流成功，再检查公网主页卡片、演示、视频、MP4 Range、移动端和桌面端。

## 明确不做

- 不实现真实市场价格、交易、登录、支付和共享匿名写入。
- 不把 `J:` 本机目录或任何凭据暴露到公网。
- 不创建 Windows/macOS 空下载按钮。
- 不删除、重排或重命名现有 Hub 项目。
